    Give Excalidraw a diagram agent

    Zero to Agent

    Download Excalidraw at home. Then, in 15 minutes in the room, you put an AI agent inside it and deploy the agent to RocketRide Cloud.

    Excalidraw is an open source whiteboard. You give it a RocketRide agent, in a new tab of its sidebar: name a public GitHub repo in the chat, and the agent reads the repo and draws its architecture on the canvas.

    1. Install git from git-scm.com if you don't have it.

    Mac or Linux: EACCES: permission denied when installing Yarn

    Your Node can't install tools for every user without permission. Run the same command with sudo in front and type your computer's password when it asks. Nothing shows while you type it: that's normal.

2. Create excalidraw-app/components/diagramAgent.ts. It holds no pipeline: it talks to the deployed one.
   - Start with /// <reference types="vite/client" />. Read VITE_APP_ROCKETRIDE_URI (default https://api.rocketride.ai) and VITE_APP_ROCKETRIDE_APIKEY from import.meta.env. They are in .env at the repo root. Create one RocketRideClient with them as uri and auth.
   - Export async function askDiagramAgent(messages), where messages is the chat so far: an array of { role: "user" | "assistant", content: string }. Connect if not connected. Find the deployed run: teamId is client.getAccountInfo()?.devTeam, and the token comes from client.getTaskToken({ projectId: the project_id from diagram-agent.pipe, source: "webhook_1", teamId }). A stopped run can keep its token, so also check client.getTaskStatus(token) is not completed. No token, a completed run, or an error whose text includes "not running" all mean the same thing: return the error "The diagram agent isn't running on RocketRide Cloud. Run the deploy command in Step 6.".
   - Send the chat as plain text with client.send(token, text, {}, "text/plain"). One message: send its content. More: send each turn as "role: content", oldest first, then "Answer the last user message.". The diagram is the last entry of result.answers. Strip a ``` fence if the agent added one.

      /// <reference types="vite/client" />
import { RocketRideClient } from "rocketride";
import { RequestError } from "@excalidraw/excalidraw/errors";

// Your RocketRide address and key, from .env. Vite only passes VITE_* settings to the
// browser: fine on your laptop, but never ship a real key in a deployed app.
const URI =
  import.meta.env.VITE_APP_ROCKETRIDE_URI ?? "https://api.rocketride.ai";
const APIKEY = import.meta.env.VITE_APP_ROCKETRIDE_APIKEY ?? "";

// The diagram agent runs on RocketRide Cloud. You deploy pipelines/diagram-agent.pipe to your team in
// Step 6; these two values must match that file's project_id and source.
const PROJECT_ID = "dafb1567-0f6e-4b87-a00e-74ce8bef1db7";
const SOURCE = "webhook_1";

/** One turn of the chat. */
export type ChatMessage = {
  role: "user" | "assistant";
  content: string;
};

/** A diagram on success, or an error the chat shows. */
export type DiagramResult =
  | { generatedResponse: string; error: null }
  | { generatedResponse?: null; error: RequestError };

let client: RocketRideClient | null = null;

/**
 * Sends the chat to the deployed diagram agent and returns its Mermaid diagram.
 * Never throws: a failure comes back as an error the chat shows.
 */
export async function askDiagramAgent(
  messages: readonly ChatMessage[],
): Promise<DiagramResult> {
  return runAgent(messages).then(toSuccess, toFailure);
}

async function runAgent(messages: readonly ChatMessage[]): Promise<string> {
  if (!client) {
    client = new RocketRideClient({ uri: URI, auth: APIKEY });
  }
  if (!client.isConnected()) {
    await client.connect();
  }

  const token = await findRun(client);
  const result = await client.send(
    token,
    toTranscript(messages),
    {},
    "text/plain",
  );
  const answers = (result?.answers as unknown[] | undefined) ?? [];
  const answer = String(answers[answers.length - 1] ?? "");

  // A wrong Anthropic key fails inside the agent and comes back as the answer.
  if (/^\**LLM error/.test(answer)) {
    throw new RequestError({ message: answer, status: 502 });
  }
  if (!answer.trim()) {
    throw new RequestError({
      message: "The agent finished without a diagram.",
      status: 502,
    });
  }

  return toMermaid(answer);
}

/** Finds the agent's deployed run on your team, or explains how to start it. */
async function findRun(client: RocketRideClient): Promise<string> {
  const teamId = client.getAccountInfo()?.devTeam;
  try {
    const token = teamId
      ? await client.getTaskToken({
          projectId: PROJECT_ID,
          source: SOURCE,
          teamId,
        })
      : undefined;
    // A stopped run can keep its token, so check that it's still running.
    if (token && !(await client.getTaskStatus(token)).completed) {
      return token;
    }
  } catch (error) {
    if (!String(error).includes("not running")) {
      throw error;
    }
  }
  throw new RequestError({
    message:
      "The diagram agent isn't running on RocketRide Cloud. Run the deploy command in Step 6.",
    status: 503,
  });
}

/** Writes the chat as plain text: earlier turns first, the newest request last. */
function toTranscript(messages: readonly ChatMessage[]): string {
  if (messages.length === 1) {
    return messages[0].content;
  }

  const lines: string[] = ["Conversation so far:"];
  for (const message of messages) {
    lines.push(`${message.role}: ${message.content}`);
  }
  lines.push("", "Answer the last user message.");
  return lines.join("\n");
}

/** Keeps only the Mermaid code, in case the agent wrapped it in a ``` fence anyway. */
function toMermaid(answer: string): string {
  const fence = answer.match(/```(?:mermaid)?\s*\n([\s\S]*?)```/);
  if (fence) {
    return fence[1].trim();
  }
  return answer.trim();
}

function toSuccess(mermaid: string): DiagramResult {
  return { generatedResponse: mermaid, error: null };
}

function toFailure(error: unknown): DiagramResult {
  if (error instanceof RequestError) {
    return { error };
  }

  let message = String(error);
  if (error instanceof Error) {
    message = error.message;
  }
  return {
    error: new RequestError({
      message: `RocketRide error: ${message}`,
      status: 500,
    }),
  };
}

/**
 * The chat as the agent sees it. Failed requests are left out, but broken
 * diagrams stay in: the agent needs them to fix its own syntax errors.
 */
const toAgentMessages = (messages: TChat.ChatMessage[]): LLMMessage[] =>
  messages
    .filter(
      (message) =>
        message.type !== "warning" &&
        !!message.content &&
        (!message.error || message.errorType === "parse"),
    )
    .map((message) => ({
      role: message.type === "user" ? "user" : "assistant",
      content: message.content ?? "",
    }));

export const DiagramAgentPanel = () => {
  const app = useApp();
  const setAppState = useExcalidrawSetAppState();
  const [messages, setMessages] = useAtom(messagesAtom);
  const [prompt, setPrompt] = useAtom(promptAtom);
  const [isGenerating, setIsGenerating] = useAtom(isGeneratingAtom);
  const [drawnIds, setDrawnIds] = useAtom(drawnIdsAtom);

  /**
   * Draws a Mermaid diagram on the canvas and returns its element ids. With
   * `replacing`, those elements are removed in the same step, so one undo
   * brings the old diagram back.
   */
  const drawOnCanvas = async (mermaid: string, replacing: string[] = []) => {
    const { elements, files } = await parseMermaid(mermaid);
    const openSidebar = app.state.openSidebar;

    const toRemove = new Set(replacing);
    const current = app.scene.getElementsIncludingDeleted();
    if (toRemove.size) {
      app.scene.replaceAllElements(
        current.map((element) =>
          toRemove.has(element.id) && !element.isDeleted
            ? newElementWith(element, { isDeleted: true })
            : element,
        ),
      );
    }

    const before = new Set(current.map((element) => element.id));
    app.addElementsFromPasteOrLibrary({
      elements: convertToExcalidrawElements(elements, {
        regenerateIds: true,
        renderEnvironment: app.renderEnvironment,
      }),
      files: files ?? null,
      position: "center",
      fit: "scale-down",
    });
    // Adding elements can close the sidebar; keep the chat open.
    setAppState({ openSidebar });

    return app.scene
      .getElementsIncludingDeleted()
      .filter((element) => !before.has(element.id))
      .map((element) => element.id);
  };

  /** Sends the prompt after `history`, then draws the answer. */
  const ask = async (prompt: string, history: TChat.ChatMessage[]) => {
    const userMessage: TChat.ChatMessage = {
      id: randomId(),
      type: "user",
      content: prompt,
      timestamp: new Date(),
    };
    const answerId = randomId();
    const chat = [...history, userMessage];
    setMessages([
      ...chat,
      {
        id: answerId,
        type: "assistant",
        isGenerating: true,
        timestamp: new Date(),
      },
    ]);
    setIsGenerating(true);

    const finishAnswer = (patch: Partial<TChat.ChatMessage>) =>
      setMessages((current) =>
        current.map((message) =>
          message.id === answerId
            ? { ...message, ...patch, isGenerating: false }
            : message,
        ),
      );

    try {
      const result = await askDiagramAgent(toAgentMessages(chat));
      if (result.error) {
        // "network" shows the chat's retry button.
        finishAnswer({ error: result.error.message, errorType: "network" });
        return;
      }
      const mermaid = result.generatedResponse;
      try {
        setDrawnIds(await drawOnCanvas(mermaid, drawnIds));
        finishAnswer({ content: mermaid });
      } catch (error) {
        // "parse" shows the chat's "Regenerate (auto-fix)" link.
        finishAnswer({
          content: mermaid,
          error: (error as Error).message,
          errorType: "parse",
        });
      }
    } finally {
      setIsGenerating(false);
    }
  };

  const onGenerate: TTTDDialog.OnGenerate = ({ prompt }) =>
    ask(prompt, messages);

  // Asks the failed question again, in place of the failed answer.
  const onRetry = (message: TChat.ChatMessage) => {
    const index = messages.findIndex(({ id }) => id === message.id);
    const question = messages[index - 1];
    if (index < 1 || question?.type !== "user" || !question.content) {
      return;
    }
    ask(question.content, messages.slice(0, index - 1));
  };

  // Adds another copy of an earlier answer to the canvas.
  const onInsertMessage = (message: TChat.ChatMessage) => {
    if (message.content) {
      drawOnCanvas(message.content).catch((error) =>
        console.warn(`Couldn't add the diagram: ${error.message}`),
      );
    }
  };

  // Removes an answer and the question that asked for it.
  const onDeleteMessage = (messageId: string) => {
    const index = messages.findIndex((message) => message.id === messageId);
    if (index < 0) {
      return;
    }
    const start = messages[index - 1]?.type === "user" ? index - 1 : index;
    setMessages([...messages.slice(0, start), ...messages.slice(index + 1)]);
  };

  return (
    <ChatInterface
      chatId="diagram-agent"
      messages={messages}
      currentPrompt={prompt}
      onPromptChange={setPrompt}
      onGenerate={onGenerate}
      isGenerating={isGenerating}
      onInsertMessage={onInsertMessage}
      onDeleteMessage={onDeleteMessage}
      onRetry={onRetry}
      onAiRepairClick={() => onGenerate({ prompt: REPAIR_PROMPT })}
      renderWelcomeScreen={() => <WelcomeScreen />}
    />
  );
};

    Reference

    Words you will hear

    Nothing here needs a computer science degree. Every term the steps use is in this list.

    The ideas

    PipelineA chain of steps that runs in RocketRide. Data goes in one end, a result comes out the other.
    AgentAn AI that decides what to do, uses tools to find things out, and then answers.
    ToolSomething an agent can use while it works. Here, a tool that reads public files from GitHub.
    LLMLarge language model. The AI that reads and writes text. Here, Claude.
    PromptThe written instructions you give a model, an agent, or a coding agent.
    Coding agentAn AI that writes and checks code in your project, such as Claude Code. Step 5 can use one.
    IntegrationAdding a new capability to an app that already exists, instead of building one from scratch.
    SDKA library that lets your code talk to a service. Here, the RocketRide TypeScript SDK.

    The tools

    RocketRideAn open source runtime for AI pipelines, with a C++ engine and a cloud you deploy to.
    ExcalidrawAn open source whiteboard for diagrams that look hand drawn. The app you add the agent to.
    MermaidA short text format for diagrams. The agent writes it and Excalidraw draws it.
    ExplorerThe file list on the left of your editor. Right-click a folder there to make a new file in it.
    TerminalThe text window where you type commands like yarn start.
    YarnThe tool that installs a JavaScript project's packages and runs it. Excalidraw uses Yarn 1.
    WorkspaceOne app inside a bigger project. Excalidraw's repo holds several; excalidraw-app is the one you run.
    ViteThe tool that runs Excalidraw on your laptop and reloads it when a file changes. It reads .env when it starts.
    TypeScriptJavaScript with types. Your editor uses them to put red squiggles under mistakes.
    API keyThe password a service gives you so your code can call it.
    DeployCopy a pipeline to RocketRide Cloud as a new version, so it runs there instead of on your laptop.
    TeamA group in your RocketRide account that a deployed pipeline belongs to. You deploy the agent to your team.
    VariableA setting saved in RocketRide Cloud under Settings → Environment Variables, such as your Anthropic key. Deployed pipelines read it from there.

    The pieces of this project

    Diagram agent tabThe brain button in Excalidraw's sidebar. It opens the chat where your agent answers.
    .envThe settings file with your RocketRide address and key. rocketride login writes it and tells git to ignore it, so it never gets committed.
    rocketride loginThe command that signs you in to RocketRide, makes an API key, and saves it in .env.
    VITE_The prefix Vite needs before it passes a setting from .env to the app in the browser.
    RocketRide clientThe SDK object in diagramAgent.ts that connects to RocketRide and runs the agent.
    Dev serverWhat yarn start starts: Excalidraw at localhost:3001 while you work.
    WebhookThe pipeline step that receives data sent to it, here the chat from Excalidraw.
    WhitelistThe list of web addresses the GitHub tool may read. Anything else is refused.

    What's in the pipeline

    The pipeline in pipelines/diagram-agent.pipe has seven parts. The three in bold make it an agent: it decides, uses a tool, then answers.

    PartWhat it does
    WebhookReceives the chat from Excalidraw.
    QuestionTurns the chat into a question for the agent.
    AgentFollows its instructions, decides what to read, and writes the Mermaid diagram.
    ClaudeThe model the agent thinks with.
    MemoryWhere the agent keeps notes while it works.
    GitHub toolReads public files from GitHub. It can only read, and only from raw.githubusercontent.com.
    AnswersSends the diagram back to Excalidraw.
