    01

    RocketRide workshop / project 2 of 3

    Give Excalidraw a diagram agent

    Zero to Agent

    In 15 minutes you put an AI agent inside a real drawing app. Clone the app, run one command, add two files.

    What you are building

    Excalidraw is an open source whiteboard for diagrams that look hand drawn. It has a Text to diagram dialog: you describe a diagram in a chat, and Excalidraw draws it. On excalidraw.com, Excalidraw's own AI service answers that chat. When you run Excalidraw on your laptop, nothing is behind the dialog, so it fails.

    You put a RocketRide agent behind it. Ask about a public GitHub repo and the agent reads the repo's files, then draws its architecture. Ask for a change, such as "make it top to bottom", and it draws the diagram again with the change.

    What makes it an agent

    A plain pipeline runs the same steps every time. An agent decides what to do. Given your message, it decides whether to read files from GitHub, which ones, and when it has read enough. Then it answers with Mermaid, a short text format for diagrams, and Excalidraw turns that into shapes.

    Where RocketRide comes in

    The agent runs on RocketRide Cloud. Excalidraw talks to it through the RocketRide TypeScript SDK: one client, one call.

    Add the diagram agent

    Ask a coding agent to write two files, or paste them yourself. Pick a tab below.

    The two files

    • excalidraw-app/components/diagramAgent.ts is new. It is the whole integration. It connects to RocketRide with the keys from .env.local, describes the agent's pipeline, and exports askDiagramAgent(), which sends the chat and returns the diagram.

    The pipeline has seven parts. The three in bold are what make it an agent: it decides, uses a tool, then answers.

    PartWhat it does
    WebhookReceives the chat from Excalidraw.
    QuestionTurns the chat into a question for the agent.
    AgentFollows its instructions, decides what to read, and writes the Mermaid diagram.
    ClaudeThe model the agent thinks with.
    MemoryWhere the agent keeps notes while it works.
    GitHub toolReads public files from GitHub. It can only read, and only from raw.githubusercontent.com.
    AnswersSends the diagram back to Excalidraw.

/** One turn of the text-to-diagram chat, as Excalidraw sends it. */
export type ChatMessage = {
  role: "user" | "assistant";
  content: string;
};

/** What Excalidraw's text-to-diagram dialog expects back. */
export type DiagramResult =
  | { generatedResponse: string; error: null }
  | { generatedResponse?: null; error: RequestError };

let client: RocketRideClient | null = null;

/**
 * Sends the chat to the diagram agent and returns its Mermaid diagram.
 * Never throws: a failure comes back as an error the dialog shows under the chat.
 */
export async function askDiagramAgent(
  messages: readonly ChatMessage[],
): Promise<DiagramResult> {
  return runAgent(messages).then(toSuccess, toFailure);
}

async function runAgent(messages: readonly ChatMessage[]): Promise<string> {
  if (!client) {
    client = new RocketRideClient({
      uri: env.ROCKETRIDE_URI,
      auth: env.ROCKETRIDE_APIKEY,
      env,
    });
  }
  if (!client.isConnected()) {
    await client.connect();
  }

  // useExisting reuses the pipeline if it's already running.
  const { token } = await client.use({ pipeline: PIPELINE, useExisting: true });
  const result = await client.send(
    token,
    toTranscript(messages),
    {},
    "text/plain",
  );
  const answers = (result?.answers as unknown[] | undefined) ?? [];
  const answer = String(answers[answers.length - 1] ?? "");

  // A wrong Anthropic key fails inside the running pipeline. Stop it, so the next try
  // starts fresh with the key from .env.local.
  if (answer.startsWith("**LLM error**")) {
    await client.terminate(token);
    throw new RequestError({ message: answer, status: 502 });
  }
  if (!answer.trim()) {
    throw new RequestError({
      message: "The agent finished without a diagram.",
      status: 502,
    });
  }

  return toMermaid(answer);
}

/** Writes the chat as plain text: earlier turns first, the newest request last. */
function toTranscript(messages: readonly ChatMessage[]): string {
  if (messages.length === 1) {
    return messages[0].content;
  }

  const lines: string[] = ["Conversation so far:"];
  for (const message of messages) {
    lines.push(`${message.role}: ${message.content}`);
  }
  lines.push("", "Answer the last user message.");
  return lines.join("\n");
}

/** Keeps only the Mermaid code, in case the agent wrapped it in a ``` fence anyway. */
function toMermaid(answer: string): string {
  const fence = answer.match(/```(?:mermaid)?\s*\n([\s\S]*?)```/);
  if (fence) {
    return fence[1].trim();
  }
  return answer.trim();
}

function toSuccess(mermaid: string): DiagramResult {
  return { generatedResponse: mermaid, error: null };
}

function toFailure(error: unknown): DiagramResult {
  if (error instanceof RequestError) {
    return { error };
  }

  let message = String(error);
  if (error instanceof Error) {
    message = error.message;
  }
  return {
    error: new RequestError({
      message: `RocketRide error: ${message}`,
      status: 500,
    }),
  };
}

    excalidraw-app/components/AI.tsx
    import {
  DiagramToCodePlugin,
  exportScene,
  getNonDeletedElements,
  getTextFromElements,
  parseSSEStream,
  TTDDialog,
  THEME,
  useOnExcalidrawStateChange,
} from "@excalidraw/excalidraw";
import { getDataURL } from "@excalidraw/excalidraw/data/blob";
import { safelyParseJSON } from "@excalidraw/common";

import type { StreamChunk } from "@excalidraw/excalidraw";
import type { ExcalidrawImperativeAPI } from "@excalidraw/excalidraw/types";

import { cacheMermaidChunks } from "../data/cacheMermaidChunks";
import { TTDIndexedDBAdapter } from "../data/TTDStorage";

import { askDiagramAgent } from "./diagramAgent";

export const AIComponents = ({
  excalidrawAPI,
}: {
  excalidrawAPI: ExcalidrawImperativeAPI;
}) => {
  useOnExcalidrawStateChange(
    (appState) => appState.openDialog?.name === "ttd",
    (isTTDDialogOpen) => {
      if (isTTDDialogOpen) {
        cacheMermaidChunks();
      }
    },
  );

  return (
    <>
      <DiagramToCodePlugin
        generate={async ({ frame, children, onPartial }) => {
          const appState = excalidrawAPI.getAppState();

          // SAFETY: This should never happen, but log it just in case
          if (children.some((el) => el.isDeleted)) {
            console.error(
              "[NONDELETED][INVARIANT] Generated children elements should not be `isDeleted: true`",
            );
          }

          const blob = await exportScene({
            type: "jpeg",
            data: {
              elements: getNonDeletedElements(children),
              appState,
              files: excalidrawAPI.getFiles(),
            },
            config: {
              exportingFrame: frame,
              theme: appState.exportWithDarkMode ? THEME.DARK : THEME.LIGHT,
            },
          });

          const dataURL = await getDataURL(blob);

          const textFromFrameChildren = getTextFromElements(children);

          const response = await fetch(
            `${
              import.meta.env.VITE_APP_AI_BACKEND
            }/v1/ai/diagram-to-code/generate-streaming`,
            {
              method: "POST",
              headers: {
                Accept: "text/event-stream",
                "Content-Type": "application/json",
              },
              body: JSON.stringify({
                texts: textFromFrameChildren,
                image: dataURL,
                theme: appState.theme,
              }),
            },
          );

          if (!response.ok) {
            const text = await response.text();
            const errorJSON = safelyParseJSON(text);

            if (!errorJSON) {
              throw new Error(text);
            }

            if (errorJSON.statusCode === 429) {
              return {
                html: `<html>
                <body style="margin: 0; text-align: center">
                <div style="display: flex; align-items: center; justify-content: center; flex-direction: column; height: 100vh; padding: 0 60px">
                  <div style="color:red">Too many requests today,</br>please try again tomorrow!</div>
                  </br>
                  </br>
                  <div>You can also try <a href="${
                    import.meta.env.VITE_APP_PLUS_LP
                  }/plus?utm_source=excalidraw&utm_medium=app&utm_content=d2c" target="_blank" rel="noopener">Excalidraw+</a> to get more requests.</div>
                </div>
                </body>
                </html>`,
              };
            }

            throw new Error(errorJSON.message || text);
          }

          const reader = response.body?.getReader();

          if (!reader) {
            throw new Error("Generation failed (invalid response)");
          }

          let html = "";
          let streamError: Error | null = null;

          for await (const data of parseSSEStream(reader)) {
            if (data === "[DONE]") {
              break;
            }

            const chunk = safelyParseJSON(data) as StreamChunk | null;

            if (!chunk) {
              continue;
            }

            switch (chunk.type) {
              case "content": {
                if (chunk.delta) {
                  html += chunk.delta;
                  onPartial?.(html);
                }
                break;
              }
              case "error": {
                streamError = new Error(
                  chunk.error.message || "Generation failed",
                );
                break;
              }
              case "done": {
                break;
              }
            }
          }

          if (streamError) {
            throw streamError;
          }

          if (!html.trim()) {
            throw new Error("Generation failed (invalid response)");
          }

          return {
            html,
          };
        }}
      />

      <TTDDialog
        onTextSubmit={async (props) => {
          const { onChunk, onStreamCreated, messages } = props;

          // RocketRide: the diagram agent answers instead of Excalidraw's AI backend.
          onStreamCreated?.();
          const result = await askDiagramAgent(messages);
          if (result.generatedResponse) {
            onChunk?.(result.generatedResponse);
          }

          return result;
        }}
        persistenceAdapter={TTDIndexedDBAdapter}
      />
    </>
  );
};

    A file wasn't pasted fully or wasn't saved. The red box, or the terminal, names the file. Copy that file's box in Step 5 again, paste over everything, and save. The page reloads by itself.

    The app opened on a different port

    Something else is using port 3001, so Vite took the next free one and printed it, for example localhost:3002. Open that.

    Take it further

    • Change how the agent draws: edit the instructions in diagramAgent.ts (for example "Group the parts into subgraphs"), save, and send a new message. The running agent keeps its old instructions until it stops, so if nothing changes, give it a few minutes and try again.
    • Let the agent read more of GitHub: add a second whitelistPattern to the GitHub tool, such as "^https://api\\.github\\.com/repos/", and tell it in the instructions what it can find there.
    Before you deploy an app like this

    Vite puts VITE_* settings into the browser bundle. That's fine on your laptop, but never ship a build with a real API key in it.

    When you're done, press Ctrl+C in the terminal to stop the app.

    Reference

    Words you will hear

    Nothing here needs a computer science degree. Every term the steps use is in this list.

    The ideas

    PipelineA chain of steps that runs in RocketRide. Data goes in one end, a result comes out the other.
    AgentAn AI that decides what to do, uses tools to find things out, and then answers.
    ToolSomething an agent can use while it works. Here, a tool that reads public files from GitHub.
    LLMLarge language model. The AI that reads and writes text. Here, Claude.
    PromptThe written instructions you give a model, an agent, or a coding agent.
    Coding agentAn AI that writes and checks code in your project, such as Claude Code. Step 5 can use one.
    IntegrationAdding a new capability to an app that already exists, instead of building one from scratch.
    SDKA library that lets your code talk to a service. Here, the RocketRide TypeScript SDK.

    The tools

    RocketRideAn open source runtime for AI pipelines, with a C++ engine and a cloud you deploy to.
    ExcalidrawAn open source whiteboard for diagrams that look hand drawn. The app you add the agent to.
    MermaidA short text format for diagrams. The agent writes it and Excalidraw draws it.
    ExplorerThe file list on the left of your editor. Right-click a folder there to make a new file in it.
    TerminalThe text window where you type commands like yarn start.
    YarnThe tool that installs a JavaScript project's packages and runs it. Excalidraw uses Yarn 1.
    WorkspaceOne app inside a bigger project. Excalidraw's repo holds several; excalidraw-app is the one you run.
    ViteThe tool that runs Excalidraw on your laptop and reloads it when a file changes. It reads .env.local when it starts.
    TypeScriptJavaScript with types. Your editor uses them to put red squiggles under mistakes.
    API keyThe password a service gives you so your code can call it.

    The pieces of this project

    Text to diagramThe Excalidraw dialog where you describe a diagram in a chat. Your agent answers it.
    .env.localThe settings file with your RocketRide address and your keys. git ignores it, so it never gets committed.
    VITE_The prefix Vite needs before it passes a setting from .env.local to the app in the browser.
    RocketRide clientThe SDK object in diagramAgent.ts that connects to RocketRide and runs the agent.
    Dev serverWhat yarn start starts: Excalidraw at localhost:3001 while you work.
    WebhookThe pipeline step that receives data sent to it, here the chat from Excalidraw.
    WhitelistThe list of web addresses the GitHub tool may read. Anything else is refused.
