    Specter Mutual

    Zero to a deployed app

    From an empty folder to a live app in your workspace: an AI agent that decides, a policy engine that holds it to the rules, and a claims portal people can use.

    What you are building

    An AI claims reviewer for Specter Mutual, a fictional insurer that covers paranormal damage. A policyholder files a claim. A RocketRide agent reads it and recommends approve, deny or escalate. A policy engine, plain code with no AI in it, checks that recommendation against the rules before anyone sees it. A claims portal puts it all on one page: the claim form on the left, the adjuster console on the right.

    The idea

    An agent can be talked into things. Plain code can't. The agent recommends and the engine decides: AI for judgment, code for guarantees.

    This is the last of three projects, and the one that goes all the way: the alarm clock deployed an app Claude wrote, the notepad added AI to an app that already existed, and this one starts from an empty folder, builds an agent and a portal, and deploys it to your workspace.

    rocketride: command not found

    pip put the command in a folder that isn't on your PATH. Run it through Python instead, with the same arguments: python3 -m rocketride.cli.main init (Windows: python -m rocketride.cli.main init), and the same for app create.

    pip won't install

    No internet, or a VPN or proxy blocking it: switch networks. externally-managed-environment means a system Python: make a virtual environment in the project folder first with python3 -m venv .venv, activate it, and run the install again.

    Probing http://localhost:5565 ... Connect call failed

    Init didn't find .env, so it looked for a RocketRide server on your laptop. Either .env isn't saved, or it went into another folder because the editor has a different folder open. Open your project folder with File, Open Folder, make .env there, save it, and run rocketride init again.

    Error: No authorization provided

    Init didn't find your key. Check that .env sits in the folder the terminal is in (not in a subfolder), that it has both lines spelled exactly as shown, and that it's saved. This version of rocketride can't sign in through the browser, so the key in .env is required.

    UnicodeDecodeError ... byte 0xff

    .env was saved as UTF-16. Open it in the editor, click UTF-16 LE in the status bar at the bottom right, choose Save with Encoding, then UTF-8. Or delete it and make it again with New File.

    Stored credentials ... were rejected

    The key is wrong or was revoked. Create a new one at cloud.rocketride.ai, paste it into .env, save, and run rocketride init again.

    pnpm not found during app create

    Install it with npm install -g pnpm@latest (Node 20+ first, from nodejs.org), restart your editor so its terminal sees it, then run the create command again.

    I left out --developer, or used the wrong id

    Without --developer the app id becomes local.specter-mutual, which can't deploy. Before you edit anything else, delete apps/specter-mutual/ and run the create command again with the right id. If you've already started building, see The Deploy tab is read-only in Step 6.

    package.json shows red squiggles

    A comma or quote went missing. Each line inside "appManifest" ends with a comma except the last one. Compare with the box above, fix the line, and save. If there's no "authenticated" line at all, add "authenticated": true, under the "include" line.

    Beat 3's policy engine

    Plain Python, no AI. It goes in the project folder itself, next to .env.

    policy.py
    import json
from datetime import date

# Coverage limits in dollars. None = not covered.
POLICY = {
    "poltergeist_damage": {"basic": 1000, "premium": 5000},
    "cold_spots_hvac":    {"basic": None, "premium": 2000},
    "ectoplasm_cleanup":  {"basic": 500,  "premium": 1500},
    "possession":         {"basic": None, "premium": None},
}
FILING_WINDOW_DAYS = 30
HUMAN_REVIEW_OVER = 3000
DECISIONS = {"approve", "deny", "escalate"}

def parse_decision(raw):
    # The agent is told to return JSON, but agents don't always listen.
    if isinstance(raw, dict):
        return raw
    try:
        start, end = raw.index("{"), raw.rindex("}") + 1
        return json.loads(raw[start:end])
    except ValueError:
        return {"category": "other", "recommendation": "escalate",
                "reasoning": "(agent output unreadable)", "letter": ""}

def adjudicate(claim, raw_decision):
    agent = parse_decision(raw_decision)
    category = agent.get("category", "other")
    recommended = agent.get("recommendation")
    if recommended not in DECISIONS:
        recommended = "escalate"

    amount = float(claim["amount"])
    tier = str(claim["tier"]).lower()
    days_late = (date.fromisoformat(claim["filedDate"])
                 - date.fromisoformat(claim["incidentDate"])).days

    # 1. Hard rules. These ignore what the agent recommended.
    limit, rule = None, None
    if days_late > FILING_WINDOW_DAYS:
        decision, rule = "deny", (f"Filed {days_late} days after the incident "
                                  f"(limit is {FILING_WINDOW_DAYS}).")
    elif category not in POLICY:
        decision, rule = "escalate", f"Category '{category}' is not in the policy."
    elif POLICY[category][tier] is None:
        decision, rule = "deny", f"'{category}' is not covered on the {tier} tier."
    elif amount > HUMAN_REVIEW_OVER:
        decision, rule = "escalate", (f"Claims over ${HUMAN_REVIEW_OVER:,} "
                                      f"require a human adjuster.")
    else:
        # 2. Within policy: the agent may be stricter, never more generous.
        limit = POLICY[category][tier]
        decision = recommended

    # 3. Payout never exceeds the coverage limit or the amount claimed.
    payout = min(amount, limit) if decision == "approve" else 0

    notes = []
    if decision != recommended:
        notes.append(f"Policy override: agent recommended {recommended}. {rule}")
    if decision == "approve" and payout < amount:
        rule = f"Payout capped at the ${limit:,} {tier} coverage limit."
        notes.append(rule)

    # 4. If the rules changed anything, the customer gets a compliant template
    #    instead of the agent's letter, which was written before the rules ran.

    /**
 * Policy engine — a 1:1 port of policy.py at the workspace root. Same rule
 * order, same output fields, same wording. Both are checked against
 * policy-cases.json so they cannot drift apart.
 */

// =============================================================================
// TYPES
// =============================================================================

export type Decision = 'approve' | 'deny' | 'escalate';

export interface Claim {
	claimId: string;
	policyholder: string;
	tier: string;
	incidentDate: string;
	filedDate: string;
	amount: number;
	description: string;
}

export interface AgentDecision {
	category?: string;
	recommendation?: string;
	reasoning?: string;
	letter?: string;
	[key: string]: unknown;
}

export interface Adjudication {
	claimId: string;
	category: string;
	decision: Decision;
	payout: number;
	letter: string;
	reasoning: string;
	policyNote: string | null;
}

// =============================================================================
// POLICY
// =============================================================================

/** Coverage limits in dollars. null = not covered. */
export const POLICY: Record<string, Record<string, number | null>> = {
	poltergeist_damage: { basic: 1000, premium: 5000 },
	cold_spots_hvac: { basic: null, premium: 2000 },
	ectoplasm_cleanup: { basic: 500, premium: 1500 },
	possession: { basic: null, premium: null },
};
export const FILING_WINDOW_DAYS = 30;
export const HUMAN_REVIEW_OVER = 3000;
const DECISIONS: ReadonlySet<string> = new Set(['approve', 'deny', 'escalate']);

const UNREADABLE: AgentDecision = {
	category: 'other',
	recommendation: 'escalate',
	reasoning: '(agent output unreadable)',
	letter: '',
};

// =============================================================================
// HELPERS
// =============================================================================

/** Python's f"{n:,}" for whole dollars. */
const fmtInt = (n: number): string => n.toLocaleString('en-US', { maximumFractionDigits: 0 });

/** Python's f"{n:,.2f}". */
const fmtMoney = (n: number): string => n.toLocaleString('en-US', { minimumFractionDigits: 2, maximumFractionDigits: 2 });

const MS_PER_DAY = 86_400_000;

/** Whole days between two YYYY-MM-DD dates, like Python's date subtraction. */
const daysBetween = (from: string, to: string): number => Math.round((Date.parse(`${to}T00:00:00Z`) - Date.parse(`${from}T00:00:00Z`)) / MS_PER_DAY);

/** The agent is told to return JSON, but agents don't always listen. */
export function parseDecision(raw: unknown): AgentDecision {
	if (raw !== null && typeof raw === 'object' && !Array.isArray(raw)) return raw as AgentDecision;
	if (typeof raw !== 'string') return { ...UNREADABLE };
	const start = raw.indexOf('{');
	const end = raw.lastIndexOf('}') + 1;
	if (start < 0 || end <= 0) return { ...UNREADABLE };
	try {
		return JSON.parse(raw.slice(start, end)) as AgentDecision;
	} catch {
		return { ...UNREADABLE };
	}
}

// =============================================================================
// ENGINE
// =============================================================================

export function adjudicate(claim: Claim, rawDecision: unknown): Adjudication {
	const agent = parseDecision(rawDecision);
	const category = agent.category ?? 'other';
	let recommended = agent.recommendation as string;
	if (!DECISIONS.has(recommended)) recommended = 'escalate';

	const amount = Number(claim.amount);
	const tier = String(claim.tier).toLowerCase();
	const daysLate = daysBetween(claim.incidentDate, claim.filedDate);

	// 1. Hard rules. These ignore what the agent recommended.
	let limit: number | null = null;
	let rule: string | null = null;
	let decision: Decision;
	if (daysLate > FILING_WINDOW_DAYS) {
		decision = 'deny';
		rule = `Filed ${daysLate} days after the incident (limit is ${FILING_WINDOW_DAYS}).`;
	} else if (!(category in POLICY)) {
		decision = 'escalate';
		rule = `Category '${category}' is not in the policy.`;
	} else if (POLICY[category][tier] === null) {
		decision = 'deny';
		rule = `'${category}' is not covered on the ${tier} tier.`;
	} else if (amount > HUMAN_REVIEW_OVER) {
		decision = 'escalate';
		rule = `Claims over $${fmtInt(HUMAN_REVIEW_OVER)} require a human adjuster.`;
	} else {
		// 2. Within policy: the agent may be stricter, never more generous.
		limit = POLICY[category][tier];
		decision = recommended as Decision;
	}

	// 3. Payout never exceeds the coverage limit or the amount claimed.
	const payout = decision === 'approve' ? Math.min(amount, limit as number) : 0;

	const notes: string[] = [];
	if (decision !== recommended) notes.push(`Policy override: agent recommended ${recommended}. ${rule}`);
	if (decision === 'approve' && payout < amount) {
		rule = `Payout capped at the $${fmtInt(limit as number)} ${tier} coverage limit.`;
		notes.push(rule);
	}

	// 4. If the rules changed anything, the customer gets a compliant template
	//    instead of the agent's letter, which was written before the rules ran.
	let letter = String(agent.letter ?? '');
	if (notes.length > 0 || !letter) {
		const outcome = { approve: `approved for $${fmtMoney(payout)}`, deny: 'denied', escalate: 'referred to a human adjuster' }[decision];
		const reason = rule ? ` Reason: ${rule}` : '';
		letter = `Dear ${claim.policyholder},\n\nYour claim ${claim.claimId} has been ${outcome}.${reason}\n\nSpecter Mutual Claims`;
	}

	return {
		claimId: claim.claimId,
		category,
		decision,
		payout,
		letter,
		reasoning: String(agent.reasoning ?? ''),
		policyNote: notes.length > 0 ? notes.join(' ') : null,
	};
}

import type { useShellConnection } from 'shell';
import claimsPipe from '../../../pipelines/claims.pipe';
import { adjudicate, type Adjudication, type Claim } from './policy';

// =============================================================================
// TYPES
// =============================================================================

export interface ClaimForm {
	policyholder: string;
	tier: 'basic' | 'premium';
	incidentDate: string;
	amount: string;
	description: string;
}

export interface ClaimResult extends Adjudication {
	claim: Claim;
}

/** The shell's client — its bundled type, not the standalone rocketride package's. */
export type ShellClient = NonNullable<ReturnType<typeof useShellConnection>['client']>;

type PipelineConfig = NonNullable<Parameters<ShellClient['use']>[0]>['pipeline'];

// =============================================================================
// PURE HELPERS
// =============================================================================

const FIRST_CLAIM_NUMBER = 1001;

/**
 * The pipeline reports model failures as an ordinary answer. The LLM node
 * writes "**LLM error** — …", the agent "LLM error: Exception: …".
 */
const LLM_ERROR = /^\s*(\*\*)?LLM error\b/;

/** Local date as YYYY-MM-DD. */
export function todayIso(now: Date = new Date()): string {
	const pad = (n: number) => String(n).padStart(2, '0');
	return `${now.getFullYear()}-${pad(now.getMonth() + 1)}-${pad(now.getDate())}`;
}

const MAX_WHOLE_DIGITS = 9;

/**
 * Filter typed or pasted text down to a dollar amount: digits and one
 * decimal point with at most two places. Anything else is dropped.
 */
export function sanitizeAmount(raw: string): string {
	const [whole, ...rest] = raw.replace(/[^\d.]/g, '').split('.');
	const dollars = whole.slice(0, MAX_WHOLE_DIGITS);
	return rest.length === 0 ? dollars : `${dollars}.${rest.join('').slice(0, 2)}`;
}

/** seq is the number of claims already filed this session. */
export function buildClaim(form: ClaimForm, seq: number, filedDate: string): Claim {
	return {
		claimId: `SM-${FIRST_CLAIM_NUMBER + seq}`,
		policyholder: form.policyholder.trim(),
		tier: form.tier,
		incidentDate: form.incidentDate,
		filedDate,
		amount: Number(form.amount),
		description: form.description.trim(),
	};
}

/**
 * The agent's answer, or '' (which adjudicate() turns into an escalation).
 * Throws on a reported model failure so it surfaces as an error, not a claim.
 */
export function readAnswer(result: { [key: string]: unknown } | undefined): unknown {
	const answers = result?.answers as unknown[] | undefined;
	const answer = answers?.[0] ?? '';
	if (typeof answer === 'string' && LLM_ERROR.test(answer)) throw new Error(answer);
	return answer;
}

// =============================================================================
// PIPELINE
// =============================================================================

let tokenPromise: Promise<string> | null = null;

/** Start (or attach to) the claims pipeline once per session. */
function claimsToken(client: ShellClient): Promise<string> {
	tokenPromise ??= client.use({ pipeline: claimsPipe as unknown as PipelineConfig, useExisting: true }).then((r) => r.token);
	// A failed start must not poison every later submit.
	tokenPromise.catch(() => {
		tokenPromise = null;
	});
	return tokenPromise;
}

/**
 * Stop any running claims task. Variables are read when a task starts, so
 * after the key changes the next submit must start a fresh one.
 */
export async function discardClaimsTask(client: ShellClient): Promise<void> {
	tokenPromise = null;
	const pipe = claimsPipe as unknown as { project_id: string; source: string };
	const token = await client.getTaskToken({ projectId: pipe.project_id, source: pipe.source });
	if (token) await client.terminate(token);
}

export async function submitClaim(client: ShellClient, claim: Claim): Promise<ClaimResult> {
	const token = await claimsToken(client);
	const result = await client.send(token, JSON.stringify(claim), { name: `${claim.claimId}.json` }, 'text/plain');
	return { ...adjudicate(claim, readAnswer(result)), claim };
}

    /**
 * The Anthropic key the claims pipeline needs. It lives in the signed-in
 * user's RocketRide Variables (server side): the pipeline's
 * ${ROCKETRIDE_ANTHROPIC_KEY} is filled in from there when a run starts.

import type { ShellClient } from './claims';

export const ANTHROPIC_KEY = 'ROCKETRIDE_ANTHROPIC_KEY';

const MIN_KEY_LENGTH = 20;

/** Whether the merged environment (user, team, org) defines the key. Names only, no values. */
export function hasAnthropicKey(keyNames: string[]): boolean {
	return keyNames.includes(ANTHROPIC_KEY);
}

/** Why a pasted key cannot be right, or null when it looks like an Anthropic key. */
export function keyProblem(value: string): string | null {
	const key = value.trim();
	if (!key) return 'Paste your Anthropic API key.';
	if (!key.startsWith('sk-ant')) return 'Anthropic keys start with "sk-ant".';
	if (key.length < MIN_KEY_LENGTH) return 'That key looks too short.';
	return null;
}

/** The user's variables with the key set. setEnv replaces the whole scope, so everything else is kept. */
export function withAnthropicKey(env: Record<string, string>, value: string): Record<string, string> {
	return { ...env, [ANTHROPIC_KEY]: value.trim() };
}

/** Whether a pipeline error means Anthropic rejected the key (a 401). */
export function isKeyRejected(message: string): boolean {
	return /LLM error/.test(message) && /\b401\b|authentication/i.test(message);
}

// =============================================================================
// SHELL CALLS
// =============================================================================

export async function userHasAnthropicKey(client: ShellClient): Promise<boolean> {
	return hasAnthropicKey(await client.account.getEnvironmentKeys());
}

export async function saveAnthropicKey(client: ShellClient, value: string): Promise<void> {
	const env = await client.account.getEnv('user');
	await client.account.setEnv('user', withAnthropicKey(env, value));
}

    2. src/useSpecterTheme.ts: putting the look on the page

    A small React hook. The portal's outer element spreads the style it returns and sets ROOT_ATTR, which loads the --sm-* variables and the base font for everything inside, whatever theme RocketRide itself is in.

    apps/specter-mutual/src/useSpecterTheme.ts
    /**
 * Root style for the Specter palette: the --sm-* variables plus base font
 * and colours. Also loads IBM Plex and the focus ring once.
 */

import type React from 'react';
import { useEffect } from 'react';
import { fonts, PALETTE } from './theme';

const FONT_HREF = 'https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500;600&family=IBM+Plex+Sans:wght@400;500;600;700&display=swap';

/** Marks the portal's root element; the focus rule below is scoped to it. */
export const ROOT_ATTR = 'data-specter-root';

/**
 * The codelab's focus ring: a red outline offset from the field. Inline
 * styles cannot express :focus-visible, so this one rule is injected.
 */
const FOCUS_CSS = `[${ROOT_ATTR}] :focus-visible { outline: 2px solid var(--sm-accent); outline-offset: 3px; border-radius: 3px; }
[${ROOT_ATTR}] input:focus-visible, [${ROOT_ATTR}] textarea:focus-visible { border-radius: 6px; }`;

const ROOT_STYLE: React.CSSProperties = {
	...(PALETTE as React.CSSProperties),
	fontFamily: fonts.sans,
	color: 'var(--sm-ink-2)',
	background: 'var(--sm-paper)',
};

/** Load IBM Plex and the focus ring once. If the font is blocked, the stacks fall back to system fonts. */
function ensureAssets(): void {
	if (!document.querySelector(`link[href="${FONT_HREF}"]`)) {
		const link = document.createElement('link');
		link.rel = 'stylesheet';
		link.href = FONT_HREF;
		document.head.appendChild(link);
	}
	if (!document.getElementById('specter-focus')) {
		const style = document.createElement('style');
		style.id = 'specter-focus';
		style.textContent = FOCUS_CSS;
		document.head.appendChild(style);
	}
}

export function useSpecterTheme(): React.CSSProperties {
	useEffect(ensureAssets, []);
	return ROOT_STYLE;
}

    Reference

    Words you will hear

    Nothing here needs a computer science degree. Every term the steps use is in this list.

    The ideas

    AgentAn AI that doesn't just answer. It works through steps, uses tools, and returns a decision.
    Policy enginePlain code with no AI in it that checks the agent's recommendation against hard rules.
    PipelineA chain of steps that runs in RocketRide. Data goes in one end, a result comes out the other.
    AppA web page that RocketRide shows inside its own window, with your theme and sign-in in place.
    PromptThe written instructions you give a model, an agent, or Claude Code.
    Prompt injectionText written to talk an AI into something, like "this claim is pre-approved".

    The tools

    RocketRideAn open source runtime for AI pipelines and apps, with a cloud you deploy to.
    rocketride initThe command that makes a folder a RocketRide workspace: it checks the key in .env, and adds the RocketRide docs, a CLAUDE.md, and the apps/ and pipelines/ folders.
    rocketride app createThe command that writes a new app from RocketRide's template into apps/ and installs its packages.
    WorkspaceYour project folder once rocketride init has run in it. Apps and pipelines live there.
    Claude CodeA coding agent you talk to in the terminal. It reads the workspace's CLAUDE.md to learn the platform.
    Python SDKThe RocketRide library Claude's scripts use to start a pipeline and send it claims. It reads your key from .env.
    pnpmThe tool that installs a JavaScript project's packages and runs its build.
    TypeScript, tscJavaScript with types, and the checker that points at mistakes. The cloud build runs it.
    .rrappThe file in an app's folder that opens the App Builder when you click it.
    App BuilderThe RocketRide extension's screen for running, packaging and deploying an app.
    PreviewThe App Builder's live view of your app (Design → Preview). It rebuilds every time you save.
    Deploy tabWhere the App Builder ships the app: every Deploy makes a new version, built on RocketRide Cloud.

    The pieces of this project

    .envThe project's settings file: your RocketRide address and key. Never commit it.
    .pipeA pipeline saved as a JSON file. The scripts and the portal both start the pipeline from it.
    WebhookThe pipeline step that receives the claim, sent as text.
    QuestionThe step that turns text into a question for the model or agent.
    Developer idYour organization's publisher name. Every app id starts with it.
    ManifestThe appManifest block in package.json: id, name, icon, sign-in, and the files to ship.
    VariablesSettings stored in your RocketRide account, like the Anthropic key. Pipelines read them on the server.
    PublishChoosing who sees a version. @me is your own desktop.
    FallbackA finished version of a step, for anyone stuck. Each step's Stuck? fold says how to run it.
