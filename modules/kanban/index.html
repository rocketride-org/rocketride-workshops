    Before the event / 15 minutes

    Set up at home

    Do this before you come. Conference wifi is slow, and it leaves you only the fun part for the room.

    1. Install what you're missing. An editor (VS Code, Cursor or Windsurf), Node 20 or newer and Claude Code. Skip any you already have. You don't need Python.
    2. Open a terminal. Terminal on Mac and Linux, PowerShell on Windows.
    3. Install pnpm and RocketRide. Paste this and press Enter:
      terminal
      npm install -g pnpm@latest rocketride@latest
    4. Close the terminal and open a new one, so it sees what you installed.
    5. Check everything. Paste this and press Enter:
      terminal
      node --version
pnpm --version
rocketride --version

      Three version numbers: Node v20 or higher, pnpm 10 or higher, RocketRide 1.6.0 or higher.

    6. Sign in to Claude Code. Run claude, follow its sign-in, then type /exit and press Enter. It needs a Claude Pro or Max plan, or an Anthropic Console account. No plan? Skip this and use the Files tab in Step 4.
    7. Make a RocketRide Cloud account. Sign up for RocketRide Cloud (the Sign up button at the top of this page), confirm your email, then redeem the workshop code EXCALIDRAW_WALKTHROUGH in the Have a promo code? bar at the bottom of your desktop at cloud.rocketride.ai. The code activates your plan: you don't need to buy a subscription. Kanban needs no model key.
    8. Make the project folder and go into it. Paste this and press Enter:
      terminal
      mkdir kanban
cd kanban

      The line where you type now ends in kanban. Remember where this folder is: you open it again in the room.

    9. Sign in to RocketRide. Paste this and press Enter. Your browser opens; sign in there with your RocketRide Cloud account:
      terminal
      rocketride login --uri https://api.rocketride.ai

      The browser says You're signed in. The terminal says Signed in as and your name, then a line that starts Saved ROCKETRIDE_URI.

    10. Check your developer id. Every app id starts with it, for example yourname_dev.kanban. Paste this and press Enter:
      terminal
      rocketride app developer status

      Your developer id. A new account doesn't have one yet: do the next action.

    11. Claim one, if you don't have one. Pick something like yourname_dev (letters and underscores). It can't be renamed later. Copy this, put your pick in place of yourname_dev, and press Enter:
      terminal
      rocketride app developer register yourname_dev

    Your Node can't install tools for every user without permission. Run the same command with sudo in front and type your computer's password when it asks. Nothing shows while you type it: that's normal.

    sudo npm install -g pnpm@latest rocketride@latest

    Start the project

    Turn your kanban folder into a RocketRide project with an app in it. This is how every RocketRide project starts.

    1. Open the folder in your editor. Click File, then Open Folder, pick the kanban folder you made at home, and click Open. If the editor asks whether you trust the folder, click Trust.
    2. Open a terminal in the editor. Click Terminal, then New Terminal.

      A terminal opens at the bottom of the editor. The line where you type ends in kanban.

    3. Set up the project. Paste this and press Enter. It uses the sign-in from home, adds the RocketRide docs, and installs the packages apps need:

    4. Make the app. Paste this and press Enter. It writes a starter app from RocketRide's template:
      terminal
      rocketride app create kanban --name "Kanban"

      Created, your developer id followed by .kanban, then at apps/kanban-ui. A kanban-ui folder appears inside apps in the Explorer.

    The build / 4 minutes

    Build the board

    Replace the starter screen with the kanban board. Pick one tab: Claude Code writes it for you, or you paste the finished file.

    1. Start Claude Code. In the editor's terminal, paste this and press Enter:
      terminal
      claude

      Claude Code starts and waits for your message.

    2. Copy the prompt. Click Copy on this box:
      prompt
      Build a kanban to-do board in apps/kanban-ui. Change only src/App.tsx. It is UI only: no pipelines, no server calls, no new packages.

- Three columns side by side: To do, Doing and Done, each showing how many cards it holds.
- Above them, a text box and an "Add card" button. Adding (or pressing Enter) puts a new card in To do and clears the box.
- Edit a card in place: double-click its text or click its pencil button. Enter or clicking away saves, Esc cancels, and an empty edit keeps the old text.
- Drag a card to another column, or up and down within a column to reorder it. While dragging, show a line where it will land and highlight that column.
- Each card also has a left arrow and a right arrow button to move it one column, and an x button to delete it.
- Start with three example cards, one in each column.
- Save the cards with useWorkspace() from "shell": read appState.cards, write them with updateAppState((prev) => ({ ...prev, cards })), and show "Loading your board…" until loaded is true.
- Wrap the board in <AppLayout showStatus> from "shell".
- Style it with inline styles that use the shell's --rr-* CSS variables (for example var(--rr-bg-surface), var(--rr-border), var(--rr-text-primary), var(--rr-accent)), so it follows the user's theme.

Then run pnpm typecheck in apps/kanban-ui and fix anything it reports.
    3. Paste it into Claude Code and press Enter.
    4. Wait for it to finish. Claude reads the CLAUDE.md and RocketRide docs that init added, then writes the board. When it asks permission to edit a file or run a command, choose Yes, and don't ask again for this session.

      Claude says it has rewritten apps/kanban-ui/src/App.tsx and the typecheck passes.

    5. Leave Claude Code: type /exit and press Enter.

    Claude's board will differ a little from the one in the Files tab. If Step 5 fails, paste that file over Claude's.

      /**
 * Kanban: a to-do board with three columns, rendered by the RocketRide shell.
 * Add, edit, delete and drag cards. They're saved in the workspace's appState, so they're still there next time.
 */

import React, { useState } from 'react';
import { AppLayout, useWorkspace } from 'shell';

type Column = 'todo' | 'doing' | 'done';
type Card = { id: string; text: string; column: Column };
/** Where a dragged card will land: in a column, before a card (or at the end when before is null). */
type DropAt = { column: Column; before: string | null };

const COLUMNS: { id: Column; title: string }[] = [
	{ id: 'todo', title: 'To do' },
	{ id: 'doing', title: 'Doing' },
	{ id: 'done', title: 'Done' },
];

const STARTER: Card[] = [
	{ id: 'c1', text: 'Add your first card', column: 'todo' },
	{ id: 'c2', text: 'Double-click a card to edit it', column: 'doing' },
	{ id: 'c3', text: 'Drag a card to another column', column: 'done' },
];

const Board: React.FC = () => {
	const { appState, updateAppState, loaded } = useWorkspace();
	const [draft, setDraft] = useState('');
	const [editing, setEditing] = useState<{ id: string; text: string } | null>(null);
	const [dragging, setDragging] = useState<string | null>(null);
	const [dropAt, setDropAt] = useState<DropAt | null>(null);

	const cards = (appState.cards as Card[] | undefined) ?? STARTER;
	const save = (next: Card[]) => {
		updateAppState((prev) => ({ ...prev, cards: next }));
	};

	const add = () => {
		const text = draft.trim();
		if (!text) {
			return;
		}
		save([...cards, { id: `c${Date.now()}`, text, column: 'todo' }]);
		setDraft('');
	};
	const remove = (id: string) => {
		save(cards.filter((card) => card.id !== id));
	};

	// Editing: Enter or clicking away saves, Esc cancels. Saving an empty card keeps the old text.
	const startEdit = (card: Card) => {
		setEditing({ id: card.id, text: card.text });
	};
	const finishEdit = () => {
		if (!editing) {
			return;
		}
		const text = editing.text.trim();
		if (text) {
			save(cards.map((card) => (card.id === editing.id ? { ...card, text } : card)));
		}
		setEditing(null);
	};

	/** Move a card into a column, before another card, or to the column's end when before is null. */
	const place = (id: string, column: Column, before: string | null) => {
		const card = cards.find((c) => c.id === id);
		if (!card || id === before) {
			return;
		}
		const rest = cards.filter((c) => c.id !== id);
		const moved = { ...card, column };
		const at = before ? rest.findIndex((c) => c.id === before) : -1;
		save(at < 0 ? [...rest, moved] : [...rest.slice(0, at), moved, ...rest.slice(at)]);
	};

	const endDrag = () => {
		setDragging(null);
		setDropAt(null);
	};
	const drop = () => {
		if (dragging && dropAt) {
			place(dragging, dropAt.column, dropAt.before);
		}
		endDrag();
	};

	if (!loaded) {
		return <div style={styles.loading}>Loading your board…</div>;
	}

	const marker = <div style={styles.marker} />;

	return (
		<div style={styles.board}>
			<div style={styles.addRow}>
				<input
					value={draft}
					placeholder="What needs doing?"
					onChange={(e) => {
						setDraft(e.target.value);
					}}
					onKeyDown={(e) => {
						if (e.key === 'Enter') {
							add();
						}
					}}
					style={styles.input}
				/>
				<button onClick={add} style={styles.addButton}>
					Add card
				</button>
			</div>
			<div style={styles.columns}>
				{COLUMNS.map((column, index) => {
					const inColumn = cards.filter((card) => card.column === column.id);
					const landing = dragging !== null && dropAt?.column === column.id;
					return (
						<section
							key={column.id}
							style={{ ...styles.column, ...(landing ? styles.columnOver : {}) }}
							onDragOver={(e) => {
								// Over the column but not over a card: the card lands at the end.
								e.preventDefault();
								if (dropAt?.column !== column.id || dropAt.before !== null) {
									setDropAt({ column: column.id, before: null });
								}
							}}
							onDrop={(e) => {
								e.preventDefault();
								drop();
							}}
						>
							<h2 style={styles.columnTitle}>
								{column.title} <span style={styles.count}>{inColumn.length}</span>
							</h2>
							{inColumn.map((card, k) => {
								const isEditing = editing?.id === card.id;
								return (
									<React.Fragment key={card.id}>
										{landing && dropAt?.before === card.id && marker}
										<div
											draggable={!isEditing}
											onDragStart={(e) => {
												// Firefox only starts a drag when it carries data.
												e.dataTransfer.setData('text/plain', card.id);
												e.dataTransfer.effectAllowed = 'move';
												setDragging(card.id);
											}}
											onDragEnd={endDrag}
											onDragOver={(e) => {
												// Top half of a card: land before it. Bottom half: land before the next one.
												e.preventDefault();
												e.stopPropagation();
												const box = e.currentTarget.getBoundingClientRect();
												const below = e.clientY > box.top + box.height / 2;
												const before = below ? (inColumn[k + 1]?.id ?? null) : card.id;
												if (dropAt?.column !== column.id || dropAt.before !== before) {
													setDropAt({ column: column.id, before });
												}
											}}
											onDrop={(e) => {
												e.preventDefault();
												e.stopPropagation();
												drop();
											}}
											style={{ ...styles.card, opacity: dragging === card.id ? 0.4 : 1, cursor: isEditing ? 'auto' : 'grab' }}
										>
											{isEditing ? (
												<input
													autoFocus
													value={editing.text}
													onChange={(e) => {
														setEditing({ id: card.id, text: e.target.value });
													}}
													onKeyDown={(e) => {
														if (e.key === 'Enter') {
															finishEdit();
														}
														if (e.key === 'Escape') {
															setEditing(null);
														}
													}}
													onBlur={finishEdit}
													style={styles.editInput}
												/>
											) : (
												<span
													title="Double-click to edit"
													onDoubleClick={() => {
														startEdit(card);
													}}
													style={styles.cardText}
												>
													{card.text}
												</span>
											)}
											{!isEditing && (
												<span style={styles.cardActions}>
													{index > 0 && (
														<button
															title={`Move to ${COLUMNS[index - 1].title}`}
															onClick={() => {
																place(card.id, COLUMNS[index - 1].id, null);
															}}
															style={styles.iconButton}
														>
															←
														</button>
													)}
													{index < COLUMNS.length - 1 && (
														<button
															title={`Move to ${COLUMNS[index + 1].title}`}
															onClick={() => {
																place(card.id, COLUMNS[index + 1].id, null);
															}}
															style={styles.iconButton}
														>
															→
														</button>
													)}
													<button
														title="Edit"
														onClick={() => {
															startEdit(card);
														}}
														style={styles.iconButton}
													>
														✎
													</button>
													<button
														title="Delete"
														onClick={() => {
															remove(card.id);
														}}
														style={styles.iconButton}
													>
														×
													</button>
												</span>
											)}
										</div>
									</React.Fragment>
								);
							})}
							{landing && dropAt?.before === null && marker}
							{inColumn.length === 0 && !landing && <div style={styles.empty}>Drop a card here</div>}
						</section>
					);
				})}
			</div>
		</div>
	);
};

const styles: Record<string, React.CSSProperties> = {
	board: { display: 'flex', flexDirection: 'column', gap: 16, padding: 24, fontFamily: 'var(--rr-font-family, system-ui)', color: 'var(--rr-text-primary, #111)' },
	loading: { padding: 24, color: 'var(--rr-text-secondary, #666)' },
	addRow: { display: 'flex', gap: 8, maxWidth: 520 },
	input: { flex: 1, fontSize: 14, padding: '8px 10px', borderRadius: 6, border: '1px solid var(--rr-border-input, #ccc)', background: 'var(--rr-bg-input, #fff)', color: 'var(--rr-text-primary, #111)' },
	addButton: { fontSize: 14, padding: '8px 14px', borderRadius: 6, border: 'none', cursor: 'pointer', background: 'var(--rr-accent, #3b82f6)', color: '#fff' },
	columns: { display: 'grid', gridTemplateColumns: 'repeat(3, minmax(0, 1fr))', gap: 16, alignItems: 'start' },
	column: { display: 'flex', flexDirection: 'column', gap: 8, minHeight: 200, padding: 12, borderRadius: 8, background: 'var(--rr-bg-surface, #f4f4f5)', border: '1px solid var(--rr-border, #e4e4e7)' },
	columnOver: { borderColor: 'var(--rr-accent, #3b82f6)' },
	columnTitle: { margin: '0 0 4px', fontSize: 14, fontWeight: 600, display: 'flex', alignItems: 'center', gap: 8 },
	count: { fontSize: 12, fontWeight: 500, color: 'var(--rr-text-secondary, #666)' },
	card: { display: 'flex', alignItems: 'center', gap: 8, padding: '10px 12px', borderRadius: 6, background: 'var(--rr-bg-paper, #fff)', border: '1px solid var(--rr-border, #e4e4e7)' },
	cardText: { flex: 1, fontSize: 14, overflowWrap: 'anywhere' },
	editInput: { flex: 1, minWidth: 0, fontSize: 14, padding: '4px 6px', borderRadius: 4, border: '1px solid var(--rr-accent, #3b82f6)', background: 'var(--rr-bg-input, #fff)', color: 'var(--rr-text-primary, #111)' },
	cardActions: { display: 'flex', gap: 2 },
	iconButton: { fontSize: 14, lineHeight: 1, padding: '4px 6px', border: 'none', borderRadius: 4, cursor: 'pointer', background: 'transparent', color: 'var(--rr-text-secondary, #666)' },
	marker: { height: 3, borderRadius: 2, background: 'var(--rr-accent, #3b82f6)' },
	empty: { padding: '16px 0', textAlign: 'center', fontSize: 13, color: 'var(--rr-text-disabled, #999)' },
};

/** Root view: the shell frame with the board inside. */
const App: React.FC = () => {
	return (
		<AppLayout showStatus>
			<Board />
		</AppLayout>
	);
};

export default App;

    Reference

    Words you will hear

    Nothing here needs a computer science degree. Every term the steps use is in this list.

    The ideas

    AppA small web page that RocketRide shows inside its own window, with your theme and sign-in already in place.
    KanbanA board of columns for tracking work. Cards move left to right as the work gets done.
    PipelineA chain of steps that runs in RocketRide. Data goes in one end, a result comes out the other. This project doesn't need one.
    ReactA popular library for building web pages out of components. RocketRide apps are written with it.
    BuildTurning an app's source code into the files a browser loads. RocketRide Cloud does it for you.

    The tools

    RocketRideAn open source runtime for AI pipelines and apps, with a cloud you deploy to.
    TerminalThe text window where you type commands. In your editor: Terminal, New Terminal.
    rocketride commandInstalled with npm. It signs you in, sets up projects, makes apps and deploys them.
    pnpmThe tool that installs an app's packages. rocketride runs it for you.
    Claude CodeA coding agent you talk to in the terminal. It reads the project's CLAUDE.md to learn RocketRide.
    API keyThe password a service gives your code. rocketride login makes one and saves it in .env.

    The pieces of this project

    rocketride loginSigns you in through the browser and saves your key in .env, which git ignores.
    rocketride initTurns a folder into a RocketRide project: adds the docs and CLAUDE.md, and installs the packages apps need.
    rocketride app createMakes a new app from RocketRide's template, in apps/<name>-ui.
    WorkspaceYour project folder after rocketride init: your sign-in, the RocketRide docs, and the apps folder.
    TemplateThe starter app RocketRide makes for you, so every app has the same shape.
    Developer idYour publisher name. Every app id starts with it, like yourname_dev.kanban.
    appStateWhere the board keeps its cards. RocketRide saves it for you, so cards survive a reload.
    DeployUploading a new version of the app to RocketRide Cloud, which builds it.
    PublishChoosing who sees a version. @me is your own desktop.
    VersionOne numbered upload of the app. Versions never change, so each deploy makes the next one.
