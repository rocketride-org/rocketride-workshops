    01

    RocketRide workshop / project 1 of 3

    Alarm clock

    Zero to Agent

    In five minutes you build an analog alarm clock app, deploy it to RocketRide Cloud, and open it in your browser.

    What you are building

    An alarm clock app. It has a round clock face whose hands move every second, a time picker, and an alarm: when the clock reaches the time you set, the face flashes and it beeps until you press Stop.

    The notebook doesn't stop at your laptop. It deploys the app to RocketRide Cloud, which builds it, and publishes it to your own RocketRide desktop. You finish with a link that opens your clock on cloud.rocketride.ai.

    Where RocketRide comes in

    RocketRide runs AI pipelines and the apps built on them. An app is a small web page, written in React, that RocketRide shows inside its own window, with your theme and sign-in already in place. You drive everything from Python with the RocketRide SDK.

    For today that means you install no web tooling. The SDK creates the app from RocketRide's template, and RocketRide Cloud builds and hosts it.

    02

    Before the event / 10 minutes

    Set up at home

    The project itself is five minutes. Setup is ten at home, and can take the whole session on conference wifi.

    What you need

    EditorVS Code, Cursor or Windsurf, with admin rights on the laptop
    Python 3.10+python3 --version. The notebook installs everything else it needs.
    RocketRide API keyCreated in your RocketRide Cloud account
    Developer idYour organization's publisher name, the first part of every app id. Claimed once per organization (see below).

    Two shortcuts you use throughout. Command palette is Cmd+Shift+P, the search box for every command your editor knows. Extensions is Cmd+Shift+X.

    Two shortcuts you use throughout. Command palette is Ctrl+Shift+P, the search box for every command your editor knows. Extensions is Ctrl+Shift+X.

    Install the notebook extensions 4 min

    1. Open Extensions and search Python. Install the one from Microsoft (ms-python.python).
    2. Search Jupyter and install it too (ms-toolsai.jupyter).
    3. Search RocketRide and install it. You use its App Builder to claim a developer id.
    4. Reload the window if it asks.
    Done when

    The extensions show as installed, and a new .ipynb file opens as a notebook with cells.

    Using Cursor or Windsurf?

    They install from Open VSX rather than the VS Code marketplace. Python and Jupyter are published there, so the same searches work.

    Save your API key 3 min

    Do this now. A missing key is the most common thing that stops people in the room.

    1. Sign in to RocketRide Cloud and create an API key.
    2. Make a folder for the workshop. In it, create a file called .env:
      .env
      ROCKETRIDE_APIKEY=your-api-key
ROCKETRIDE_URI=https://api.rocketride.ai
    Keep it out of the notebook

    Never paste your key into a cell, and never commit a .env file. If there is no .env, the notebook's Config cell asks for the key and keeps it only for the session.

    Claim a developer id 1 min

    Every app's id starts with your organization's developer id, for example acme_labs.alarm_clock. An organization claims it once, and every member shares it. If someone in your organization already claimed one, skip this.

    1. Open the RocketRide App Builder and go to the Deploy tab.
    2. The banner asks for a developer id. Use letters and underscores only, for example acme_labs, and click Register.
    Choose carefully

    A developer id can't be renamed or removed afterwards. Only an org admin can claim it.

    Get the notebook 2 min

    Download alarm-clock.ipynb View on GitHub
    1. Save the notebook into the folder with your .env, and open the folder with File, Open Folder.
    2. Open the notebook. Click Select Kernel in the top right, choose Python Environments, and pick Python 3.10 or newer.
    3. Run the Setup cell with Shift+Enter. The first time, it installs the RocketRide SDK.
    Done when

    Setup prints a green ✅ ready.

    It asks me to install ipykernel

    Accept the prompt, or run python3 -m pip install ipykernel for that interpreter.

    Couldn't install the RocketRide SDK

    The cell prints pip's error. Usually it's no internet, or a VPN or proxy blocking it. Switch networks, then run Setup again.

    Stuck on any of this?

    Come 10 minutes early. A facilitator runs a help desk before the start, and that is the only setup help there is time for. Before then, the RocketRide Discord is the fastest route, and the docs are at docs.rocketride.org.

    Open the notebook

    Three cells, top to bottom. They install the SDK, load your key, and connect to RocketRide Cloud. Run All runs them for you.

    Done when

    All three cells ran without a red error and the last one says Connected.

    The Config cell keeps asking for my key

    There is no ROCKETRIDE_APIKEY in your environment or in a .env next to the notebook. Paste the key when asked: it's kept for the session. To skip the prompt next time, create the .env from Step 2.

    Connect fails with Invalid or expired access_token

    The key is wrong or was revoked. Create a new one in RocketRide Cloud, update your .env, restart the kernel and run the three cells again.

    04

    The build / 2 minutes, two stages

    Build the clock

    Create the app from RocketRide's template. Then draw the clock into it.

    Each stage ends with something you can see in the notebook. If a stage doesn't work, the last cell of that stage is a skip-ahead cell that puts you exactly where the stage should have ended.

    Stage 1. Create the app 1 min

    Run the Stage 1 cell. It reads your organization's developer id, then creates the app under build/apps/alarm_clock/ from RocketRide's app template:

    FileWhat it is
    package.jsonThe app's manifest: its id, name, icon and the packages it uses
    src/App.tsxThe screen. Stage 2 replaces it with the clock.
    src/AppDescriptor.tsHow RocketRide finds and shows the app
    icon.svg, README.mdThe app's icon and store listing
    Done when

    The cell prints App id: with your developer id, then the list of files.

    Your organization has no developer id yet

    Claim one in the App Builder's Deploy tab (Step 2), then run Stage 1 again. It reconnects and picks up the new id.

    Stuck? Skip ahead

    Run the cell headed # Skip ahead: run this only if the stage above didn't work at the end of Stage 1. It reconnects and creates the app again from a clean template.

    Stage 2. Draw the clock 1 min

    Run the Stage 2 cell. It writes the clock into src/App.tsx:

    • A round face with 60 ticks and 12 numerals, and hour, minute and second hands that move every second.
    • A digital readout under it.
    • An alarm: pick a time and press Set alarm. When the clock gets there, the face flashes and it beeps until you press Stop.
    Done when

    The cell prints Wrote src/App.tsx and Wrote README.md.

    Want to change it?

    The clock is the text in APP_TSX. Change a color or the beep's pitch (880), run Stage 2, then run Stage 3 to publish the new version.

    Stuck? Skip ahead

    Run the skip-ahead cell at the end of Stage 2. It writes the finished clock.

    05

    The finish / 2 minutes

    Deploy and open it

    One cell sends the app to RocketRide Cloud, waits while it builds, publishes it to your desktop, and prints the link.

    What the cell does

    1. Checks the app on your laptop: the manifest, the id, the icon and the README.
    2. Deploys it: uploads the app's source as a new version.
    3. Waits while RocketRide Cloud builds it, and prints each build step. This takes a minute or two.
    4. Publishes it to @me, your own desktop, and prints Open your clock with the link.
    Done when

    The link opens your clock and the second hand is moving. Set an alarm one minute ahead and wait for it to ring.

    The cloud build failed

    The cell prints the end of the build log. If you edited the clock, the log points at the line. Run the Stage 2 skip-ahead cell to restore the finished clock, then run Stage 3 again.

    It's still building

    The cell waits five minutes. If the build takes longer, wait a minute and run the skip-ahead cell: it publishes the newest version that finished building.

    The alarm flashes but doesn't beep

    Browsers only play sound after you click on the page. Press Set alarm to turn sound on, and check the tab isn't muted.

    The clock isn't on my desktop

    The desktop picks up new apps when it refreshes. Reload cloud.rocketride.ai, or use the link the cell printed.

    Running it again is safe: it publishes the next version, and the same link opens it.

    Reference

    Words you will hear

    Nothing here needs a computer science degree. Every term the steps use is in this list.

    The ideas

    AppA small web page that RocketRide shows inside its own window, with your theme and sign-in already in place.
    PipelineA chain of steps that runs in RocketRide. Data goes in one end, a result comes out the other. This project doesn't need one.
    ReactA popular library for building web pages out of components. RocketRide apps are written with it.
    BuildTurning an app's source code into the files a browser loads. RocketRide Cloud does it for you.

    The tools

    RocketRideAn open source runtime for AI pipelines and apps, with a cloud you deploy to.
    NotebookA file of cells (.ipynb) you run one at a time. Text cells explain, code cells do the work.
    CellOne block in a notebook. Run it with Shift+Enter.
    KernelThe Python that runs a notebook's cells. Pick it with Select Kernel.
    SDKA library that lets your code talk to a service. Here, the RocketRide Python SDK.
    API keyThe password a service gives you so your code can call it.
    App BuilderThe RocketRide extension's screen for designing, packaging and deploying apps.

    The pieces of this project

    SetupThe first code cell. Installs the RocketRide SDK and prints ready.
    ConfigThe only cell that reads your environment. Every later cell uses its CONFIG.
    ConnectOpens the shared RocketRide client.
    Skip aheadThe last cell of each stage. Puts you where the stage should have ended.
    TemplateThe starter app RocketRide creates for you, so every app has the same shape.
    Developer idYour organization's publisher name. Every app id starts with it, like acme_labs.alarm_clock.
    ManifestThe appManifest block in package.json: the app's id, name, icon and README.
    DeployUploading a new version of the app's source to RocketRide Cloud, which builds it.
    PublishChoosing who sees a version. @me is your own desktop; teams and the public store are the other choices.
    VersionOne numbered upload of the app. Versions never change, so each deploy makes the next one.
