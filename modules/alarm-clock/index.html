    01

    RocketRide workshop / project 1 of 3

    Alarm clock

    Zero to Agent

    In fifteen minutes you start a RocketRide project from nothing, the way you would at work: a few commands, then ask Claude Code for an alarm clock app. You watch it run in your editor, then deploy it to RocketRide Cloud from the editor and open it in your browser.

    What you are building

    An alarm clock app. It has a round clock face whose hands move every second, a time picker, and an alarm: when the clock reaches the time you set, the face flashes and it beeps until you press Stop.

    You do every step yourself, in a terminal and in the RocketRide extension. Nothing is scripted for you, because the point is to see how little it takes: install, initialize, create, build, deploy.

    Where RocketRide comes in

    RocketRide runs AI pipelines and the apps built on them. An app is a small web page, written in React, that RocketRide shows inside its own window, with your theme and sign-in already in place.

    The rocketride command sets up a project and creates apps from RocketRide's template. The RocketRide extension's App Builder shows the app live while you work, then deploys it. RocketRide Cloud builds it and hosts it.

    02

    Before the event / 15 minutes

    Set up at home

    The project itself is fifteen minutes. Setup is fifteen at home, and can take the whole session on conference wifi.

    What you need

    EditorVS Code, Cursor or Windsurf, with admin rights on the laptop
    Python 3.10+python3 --version (Windows: python --version)
    Node 20+ and pnpm 10+The App Builder uses them to run your app in the editor. node --version, pnpm --version
    RocketRide Cloud accountWith an active subscription. You create an API key there and save it in your project's .env (Step 3).
    Developer idYour organization's publisher name, the first part of every app id. Claimed once per organization (see below).
    Claude CodeWrites the clock. Without it, the fallback notebook has a finished one.

    Two shortcuts you use throughout. Command palette is Cmd+Shift+P, the search box for every command your editor knows. Extensions is Cmd+Shift+X.

    Two shortcuts you use throughout. Command palette is Ctrl+Shift+P, the search box for every command your editor knows. Extensions is Ctrl+Shift+X.

    Install the extensions 4 min

    1. Open Extensions and search RocketRide. Install it: its App Builder runs, deploys and publishes your app.
    2. Search Python and Jupyter and install both from Microsoft (ms-python.python, ms-toolsai.jupyter). You only need them for the fallback notebook.
    3. Reload the window if it asks.
    Done when

    The extensions show as installed, and the RocketRide icon is in the activity bar.

    Using Cursor or Windsurf?

    They install from Open VSX rather than the VS Code marketplace. The same searches work.

    Install Node and pnpm 4 min

    Install Node 20 or newer from nodejs.org, then pnpm:

    terminal
    npm install -g pnpm@latest
    Done when

    node --version prints 20 or higher and pnpm --version prints 10 or higher. Restart your editor afterwards so its terminals see them.

    Install Claude Code 3 min

    Install it from claude.com/claude-code, then run claude once in a terminal and sign in.

    Claim a developer id 1 min

    Every app's id starts with your organization's developer id, for example acme_labs.alarm_clock. An organization claims it once, and every member shares it. If someone in your organization already claimed one, write it down and skip this.

    1. Click the RocketRide icon, sign in to RocketRide Cloud, and open the App Builder. Go to the Deploy tab.
    2. The banner asks for a developer id. Use letters and underscores only, for example acme_labs, and click Register.
    Choose carefully

    A developer id can't be renamed or removed afterwards. Only an org admin can claim it.

    Practice the start 3 min

    Run Step 3, Start the project, once at home. Creating your API key and the first install are the slow parts, and it's safe to do again in the room.

    Stuck on any of this?

    Come 10 minutes early. A facilitator runs a help desk before the start, and that is the only setup help there is time for. Before then, the RocketRide Discord is the fastest route, and the docs are at docs.rocketride.org.

    03

    In the room / 4 minutes

    Start the project

    Three commands take you from an empty folder to a signed-in RocketRide project with a new app in it. This is how every RocketRide project starts.

    1. Make an empty folder for the project, for example alarm-clock. In your editor, choose File, Open Folder and open it. Then open a terminal: Terminal, New Terminal.
    2. Install RocketRide. This installs the Python package, which brings the rocketride command:
      terminal
      python3 -m pip install rocketride
      terminal
      python -m pip install rocketride
      A Mac has no plain pip command, so this runs pip through Python.
    3. Save your RocketRide key. Sign in at cloud.rocketride.ai and create an API key. Then, in the editor's Explorer, click New File, name it .env (in the project folder itself), paste these two lines, put your key in place of your-api-key, and save:
      .env
      ROCKETRIDE_URI=https://api.rocketride.ai
ROCKETRIDE_APIKEY=your-api-key
      To check, run ls -a in the terminal: it should list .env.
      Make .env in the editor, not the terminal

      On Windows, echo ... > .env in PowerShell saves the file as UTF-16, and every rocketride command then stops with UnicodeDecodeError: 'utf-8' codec can't decode byte 0xff. A file made with the editor's New File button is saved correctly. Never commit .env or paste your key into a notebook.

    4. Initialize the project. Init reads your key from .env:
      terminal
      rocketride init
      It prints Using existing credentials for https://api.rocketride.ai, downloads RocketRide's docs into .rocketride/, and writes a CLAUDE.md so Claude Code knows the platform.
    5. Create the app. Put your developer id in place of your_developer_id:
      terminal
      rocketride app create alarm_clock --name "Alarm Clock" --developer your_developer_id
      It writes the app from RocketRide's template into apps/alarm_clock/, then installs its packages with pnpm. That takes a minute the first time.
    FileWhat it is
    package.jsonThe app's manifest: its id, name, icon and the packages it uses
    alarm_clock.rrappOpens the app in the App Builder
    src/App.tsxThe screen. Claude replaces it with the clock.
    icon.svg, README.mdThe app's icon and store listing
    Done when

    Init printed Workspace initialized against https://api.rocketride.ai, and apps/alarm_clock/ is in the Explorer.

    rocketride: command not found

    pip put the command in a folder that isn't on your PATH. Run it through Python instead, with the same arguments: python3 -m rocketride.cli.main init (Windows: python -m rocketride.cli.main init).

    pip won't install

    No internet, or a VPN or proxy blocking it: switch networks. externally-managed-environment means a system Python: make a virtual environment first with python3 -m venv .venv, activate it, and run the install again.

    Probing http://localhost:5565 ... Connect call failed

    Init didn't find .env, so it looked for a RocketRide server on your laptop. Either .env isn't saved, or it went into another folder because the editor has a different folder open. Open your project folder with File, Open Folder, make .env there, save it, and run rocketride init again.

    Error: No authorization provided

    Init didn't find your key. Check that .env sits in the folder the terminal is in (not in a subfolder), that it has both lines spelled exactly as shown, and that it's saved. This version of rocketride can't sign in through the browser, so the key in .env is required.

    UnicodeDecodeError ... byte 0xff

    .env was saved as UTF-16. Open it in the editor, click UTF-16 LE in the status bar at the bottom right, choose Save with Encoding, then UTF-8. Or delete it and make it again with New File.

    Stored credentials ... were rejected

    The key is wrong or was revoked. Create a new one at cloud.rocketride.ai, paste it into .env, save, and run rocketride init again.

    pnpm not found during app create

    Install it (npm install -g pnpm@latest), restart your editor, then run pnpm install in the project folder.

    I don't know my developer id

    Open the App Builder's Deploy tab: it shows your organization's id, or asks you to claim one. If you created the app with the wrong id, see The Deploy tab is read-only in Step 5.

    04

    The build / 5 minutes

    Build the clock

    Ask Claude Code for the clock, then watch it run in the App Builder.

    Ask Claude for the clock 3 min

    1. In the same terminal, in your project folder, start Claude Code:
      terminal
      claude
    2. Ask for the clock:
      prompt
      Build a basic analog alarm clock in apps/alarm_clock: a ticking clock face with hour, minute and second hands, the digital time under it, a time picker and a Set alarm button. When the alarm time comes, flash the face and beep until I press Stop. Replace the template README and the description in package.json with a short description of the clock. Don't deploy it.

    Claude reads the CLAUDE.md and RocketRide docs that init put in the folder, so it knows how a RocketRide app is put together. Let it edit the files it asks about.

    Done when

    Claude says it has rewritten apps/alarm_clock/src/App.tsx.

    See it in the App Builder 2 min

    1. In the Explorer, open apps/alarm_clock/alarm_clock.rrapp. The App Builder opens.
    2. Go to the Design tab and pick Preview. The App Builder installs, builds and shows the app. The first build takes a moment.
    3. Set an alarm one minute ahead and wait for it to ring.
    Done when

    The preview shows your clock with the second hand moving.

    The App Builder won't open, .rrapp opens as text, or the preview never loads

    Your editor hasn't trusted the project folder yet, so it runs in Restricted Mode and the RocketRide extension stays switched off. Click Restricted Mode in the status bar (or the banner at the top), then Trust, and confirm Trust Folder and Continue. You can also run Workspaces: Manage Workspace Trust from the command palette. Then open the .rrapp file again.

    Want to change it?

    Ask Claude: a different color, a louder beep, a snooze button. The preview rebuilds every time a file is saved.

    The preview shows an error, or stays blank

    Open the Errors pane next to Preview, copy the error into Claude and ask it to fix it.

    No Claude Code, or still stuck? Use the fallback

    Download alarm-clock.ipynb into your project folder, open it, pick a Python 3.10+ kernel, and run its one code cell. It writes a finished clock into apps/alarm_clock, and the preview picks it up.

    05

    The finish / 6 minutes

    Deploy from the App Builder

    Two clicks: Deploy sends the app to RocketRide Cloud, which builds it, and Publish puts that version on your desktop.

    1. In the App Builder, go to the Deploy tab.
    2. Click Deploy. Add a comment if you like, for example first clock. The App Builder uploads the app's source as a new version, v1.
    3. Watch the version card while RocketRide Cloud builds it: uploaded, installing, checking, building. This takes a minute or two.
    4. When the build is done, click Publish to… on the version card and choose @me, your own desktop.
    5. Open cloud.rocketride.ai. Your clock is on your desktop.
    Done when

    Your clock opens on cloud.rocketride.ai and the second hand is moving.

    The build failed

    Click the failed badge on the version card to open the build log. The failure reason is at the end. Paste it into Claude and ask for a fix, check the preview, then click Deploy again.

    The Deploy tab is read-only with a namespace banner

    The app id doesn't start with your organization's developer id. The banner names the right one. The id is in three files, so ask Claude to change it, putting the banner's id in place of your_developer_id:

    prompt
    Change the developer id of apps/alarm_clock to your_developer_id in package.json, alarm_clock.rrapp and src/AppDescriptor.ts.

    Close the App Builder, open alarm_clock.rrapp again, and deploy.

    The alarm flashes but doesn't beep

    Browsers only play sound after you click on the page. Press Set alarm to turn sound on, and check the tab isn't muted.

    The clock isn't on my desktop

    The desktop picks up new apps when it refreshes. Reload cloud.rocketride.ai.

    To ship a change: ask Claude, check the preview, Deploy again, and publish the new version to @me. Versions never change, so each deploy makes the next one.

    Reference

    Words you will hear

    Nothing here needs a computer science degree. Every term the steps use is in this list.

    The ideas

    AppA small web page that RocketRide shows inside its own window, with your theme and sign-in already in place.
    PipelineA chain of steps that runs in RocketRide. Data goes in one end, a result comes out the other. This project doesn't need one.
    ReactA popular library for building web pages out of components. RocketRide apps are written with it.
    BuildTurning an app's source code into the files a browser loads. RocketRide Cloud does it for you.

    The tools

    RocketRideAn open source runtime for AI pipelines and apps, with a cloud you deploy to.
    TerminalThe text window where you type commands. In your editor: Terminal, New Terminal.
    NotebookA file of cells (.ipynb) you run one at a time. Here it only holds the fallback clock.
    SDKA library that lets your code talk to a service. Here, the RocketRide Python SDK.
    rocketride commandInstalled with the SDK. init sets up a workspace, app create makes an app.
    Claude CodeA coding agent you talk to in the terminal. It reads the workspace's CLAUDE.md to learn the platform.
    API keyThe password a service gives you so your code can call it. You create one at cloud.rocketride.ai and save it in .env.
    App BuilderThe RocketRide extension's screen for an app: Design shows it live, Deploy ships it.
    PreviewThe App Builder's live view of your app. It rebuilds every time a file is saved.

    The pieces of this project

    rocketride initTurns a folder into a RocketRide project: checks the key in .env, adds the docs and CLAUDE.md.
    rocketride app createMakes a new app from RocketRide's template under apps/.
    WorkspaceYour project folder after rocketride init: your sign-in, the RocketRide docs, and the apps/ folder.
    .rrappThe file in an app folder that opens it in the App Builder.
    FallbackThe notebook's one cell. Writes a finished clock if Claude's doesn't work.
    TemplateThe starter app RocketRide creates for you, so every app has the same shape.
    Developer idYour organization's publisher name. Every app id starts with it, like acme_labs.alarm_clock.
    ManifestThe appManifest block in package.json: the app's id, name, icon and README.
    DeployUploading a new version of the app's source to RocketRide Cloud, which builds it.
    PublishChoosing who sees a version. @me is your own desktop; teams and the public store are the other choices.
    VersionOne numbered upload of the app. Versions never change, so each deploy makes the next one.
