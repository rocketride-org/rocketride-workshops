    01

    RocketRide workshop / project 1 of 3

    Alarm clock

    Zero to Agent

    In 15 minutes you start a RocketRide project from nothing, have Claude Code build an alarm clock app, and deploy it to RocketRide Cloud.

    The alarm clock app has a round clock face whose hands move every second, a time picker, and an alarm: when the time comes, the face flashes and beeps until you press Stop. A RocketRide app is a small React web page that RocketRide shows inside its own window, with your theme and sign-in already in place.

    WhenStep

    0:003. Start the project: three commands
    0:044. Have Claude build the clock, and watch it run
    0:095. Deploy it from the App Builder
    Done when

    Your clock is ticking on cloud.rocketride.ai, published to your own desktop.

    How to use this page

    Do the numbered actions in order, one at a time. Anything you type is in a box with a Copy button. A green ✓ line tells you what you should see. Stuck? Open the grey boxes under each step.

    02

    Before the event / 15 minutes

    Set up at home

    Do this before you come. Conference wifi is slow.

    1. Install what you're missing. An editor (VS Code, Cursor or Windsurf) with admin rights on the laptop, Python 3.10 or newer, Node 20 or newer and Claude Code. Skip any you already have.
    2. Open a terminal. Terminal on Mac and Linux, PowerShell on Windows.
    3. Install pnpm. Paste this and press Enter:
      terminal
      npm install -g pnpm@latest
    4. Close the terminal and open a new one, so it sees what you installed. Restart your editor too, so its terminals see them.
    5. Check everything. Paste the box for your computer and press Enter:
      terminal
      python3 --version
node --version
pnpm --version
      terminal
      python --version
node --version
pnpm --version

      Three version numbers: Python 3.10 or higher, Node v20 or higher, pnpm 10 or higher.

    6. Sign in to Claude Code. Run claude in the terminal once and follow its sign-in. Then type /exit to leave it.
    7. Install the RocketRide extension. In your editor, open Extensions (Cmd+Shift+X on Mac, Ctrl+Shift+X on Windows and Linux), search RocketRide, and click Install. Reload the window if it asks.

      The RocketRide icon appears in the activity bar on the left.

    8. Make a RocketRide Cloud account. Sign up at cloud.rocketride.ai, confirm your email, and start a subscription.
    9. Find or claim your developer id. Every app id starts with it, for example acme_labs.alarm_clock. Click the RocketRide icon, sign in to RocketRide Cloud, open the App Builder, and go to its Deploy tab.

      The tab shows your organization's developer id. Write it down. If a banner asks you to claim one instead, do the next action.

    10. Claim one, only if asked. Type a name with letters and underscores only, for example acme_labs, and click Register. It can't be renamed or removed afterwards, and only an org admin can claim it.
    Want a head start?

    Do Step 3 once at home. Creating your API key and the first install are the slow parts, and it's safe to do again in the room.

    Mac or Linux: EACCES: permission denied when installing pnpm

    Your Node can't install tools for every user without permission. Run the same command with sudo in front and type your computer's password when it asks. Nothing shows while you type it: that's normal.

    terminal
    sudo npm install -g pnpm@latest
    Windows: running scripts is disabled on this system

    PowerShell blocks tools installed with npm until you allow them. Paste this, press Enter, close PowerShell, open a new one, and try again:

    terminal
    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
    A version is missing or too old

    Install it from the link in action 1, close the terminal, open a new one, and check again.

    Using Cursor or Windsurf?

    They install extensions from Open VSX rather than the VS Code marketplace. The same search works.

    Want the fallback notebook ready?

    Also search Extensions for Python and Jupyter and install both from Microsoft (ms-python.python, ms-toolsai.jupyter). You only need them if Claude Code can't build the clock.

    Stuck on anything

    Ask in the RocketRide Discord, read docs.rocketride.org, or come 10 minutes early for the help desk.

    03

    In the room / 4 minutes

    Start the project

    From an empty folder to a signed-in RocketRide project with a new app in it. This is how every RocketRide project starts.

    FirstOpen an empty project folder

    1. Make an empty folder for the project anywhere you like, for example alarm-clock.
    2. Open it in your editor. Click File, then Open Folder, pick the folder, and click Open. If the editor asks whether you trust the folder, click Trust.
    3. Open a terminal in the editor. Click Terminal, then New Terminal.

      A terminal opens at the bottom of the editor, in your project folder.

    4. Install RocketRide. This installs the Python package, which brings the rocketride command. Paste the box for your computer and press Enter:
      terminal
      python3 -m pip install rocketride
      terminal
      python -m pip install rocketride

      The last line starts with Successfully installed.

    File 1 of 1.env

    1. Create a RocketRide API key. Sign in at cloud.rocketride.ai and create an API key. Keep the page open so you can copy it.
    2. Make the file. In the editor's Explorer, click an empty spot below the files so nothing is selected, then click the New File icon at the top of the Explorer.
    3. Name it .env and press Enter. Spell it exactly, with the dot at the start.

      .env sits in the project folder itself, not in a subfolder, and is open in the editor.

    4. Copy the settings. Click Copy on this box:
      .env
      ROCKETRIDE_URI=https://api.rocketride.ai
ROCKETRIDE_APIKEY=your-api-key
    5. Paste into the empty file: click in it, then Cmd+V on Mac or Ctrl+V on Windows and Linux.
    6. Put in your key. Replace your-api-key with the API key you just created.
    7. Save: Cmd+S on Mac, Ctrl+S on Windows and Linux.

      The dot on the file's tab disappears, and no line still says your-api-key.

    Make .env in the editor, not the terminal

    On Windows, echo ... > .env in PowerShell saves the file in a format rocketride can't read. Never commit .env or paste your key into a notebook.

    ThenInitialize and create the app

    1. Initialize the project. It reads your key from .env. Paste this into the terminal and press Enter:
      terminal
      rocketride init

      Using existing credentials for https://api.rocketride.ai, then Workspace initialized against https://api.rocketride.ai. A .rocketride folder and a CLAUDE.md appear in the Explorer: they teach Claude Code about RocketRide.

    2. Copy the create command. Click Copy on this box:
      terminal
      rocketride app create alarm_clock --name "Alarm Clock" --developer your_developer_id
    3. Paste it into the terminal, but don't press Enter yet.
    4. Put in your developer id. Use the arrow keys to move back, and replace your_developer_id with the id you wrote down in Step 2.
    5. Press Enter. It writes the app from RocketRide's template, then installs its packages with pnpm. That takes a minute the first time.

      apps/alarm_clock/ appears in the Explorer.

    Done when

    Init printed Workspace initialized against https://api.rocketride.ai, and apps/alarm_clock/ is in the Explorer.

    What's in apps/alarm_clock/
    FileWhat it is
    package.jsonThe app's manifest: its id, name, icon and the packages it uses
    alarm_clock.rrappOpens the app in the App Builder
    src/App.tsxThe screen. Claude replaces it with the clock.
    icon.svg, README.mdThe app's icon and store listing
    rocketride: command not found

    pip put the command in a folder that isn't on your PATH. Run it through Python instead, with the same arguments: python3 -m rocketride.cli.main init (Windows: python -m rocketride.cli.main init).

    pip won't install

    No internet, or a VPN or proxy blocking it: switch networks and run the install again.

    error: externally-managed-environment

    Your Python belongs to the system (common on Linux, and on Mac with Homebrew), so pip won't install into it. Give the project its own Python instead. In the editor's terminal, in your project folder:

    1. Make the project's Python. Paste the box for your computer:
      Terminal (Mac and Linux)
      python3 -m venv .venv
      PowerShell (Windows)
      python -m venv .venv
    2. Switch to it. Paste the box for your computer:
      Terminal (Mac and Linux)
      source .venv/bin/activate
      PowerShell (Windows)
      .venv\Scripts\Activate.ps1

      The terminal's prompt now starts with (.venv).

    3. Run the install again, then carry on with the step.

    Every new terminal starts outside it: run the Switch to it line again whenever (.venv) is missing.

    Probing http://localhost:5565 ... Connect call failed

    Init didn't find .env, so it looked for a RocketRide server on your laptop. Either .env isn't saved, or it went into another folder because the editor has a different folder open. Open your project folder with File, Open Folder, make .env there, save it, and run rocketride init again.

    Error: No authorization provided

    Init didn't find your key. Check that .env sits in the folder the terminal is in (not in a subfolder), that it has both lines spelled exactly as shown, and that it's saved. This version of rocketride can't sign in through the browser, so the key in .env is required.

    UnicodeDecodeError ... byte 0xff

    .env was saved as UTF-16. Open it in the editor, click UTF-16 LE in the status bar at the bottom right, choose Save with Encoding, then UTF-8. Or delete it and make it again with New File.

    Stored credentials ... were rejected

    The key is wrong or was revoked. Create a new one at cloud.rocketride.ai, paste it into .env, save, and run rocketride init again.

    pnpm not found during app create

    Install it (npm install -g pnpm@latest), restart your editor, then run pnpm install in the project folder.

    I don't know my developer id

    Open the App Builder's Deploy tab: it shows your organization's id, or asks you to claim one. If you created the app with the wrong id, see The Deploy tab is read-only in Step 5.

    04

    The build / 5 minutes

    Build the clock

    Ask Claude Code for the clock, then watch it run in the App Builder.

    FirstAsk Claude for the clock

    1. Start Claude Code. In the same terminal, in your project folder, paste this and press Enter:
      terminal
      claude

      Claude Code starts and waits for your message.

    2. Copy the prompt. Click Copy on this box:
      prompt
      Build a basic analog alarm clock in apps/alarm_clock: a ticking clock face with hour, minute and second hands, the digital time under it, a time picker and a Set alarm button. When the alarm time comes, flash the face and beep until I press Stop. Replace the template README and the description in package.json with a short description of the clock. Don't deploy it.
    3. Paste it into Claude Code and press Enter.
    4. Wait for it to finish. Claude reads the CLAUDE.md and RocketRide docs that init put in the folder, then writes the clock. When it asks to edit a file, allow it.

      Claude says it has rewritten apps/alarm_clock/src/App.tsx.

    ThenSee it in the App Builder

    1. Open the App Builder. In the Explorer, open apps, then alarm_clock, and click alarm_clock.rrapp.

      The App Builder opens.

    2. Show the preview. Click the Design tab, then Preview. The App Builder installs, builds and shows the app. The first build takes a moment.

      Your clock, with the second hand moving.

    3. Set an alarm one minute ahead, click Set alarm, and wait.

      The face flashes and beeps until you press Stop.

    Done when

    The preview shows your clock with the second hand moving.

    The App Builder won't open, .rrapp opens as text, or the preview never loads

    Your editor hasn't trusted the project folder yet, so it runs in Restricted Mode and the RocketRide extension stays switched off. Click Restricted Mode in the status bar (or the banner at the top), then Trust, and confirm Trust Folder and Continue. You can also run Workspaces: Manage Workspace Trust from the command palette (Cmd+Shift+P on Mac, Ctrl+Shift+P on Windows and Linux). Then open the .rrapp file again.

    The preview shows an error, or stays blank

    Open the Errors pane next to Preview, copy the error into Claude and ask it to fix it.

    Want to change it?

    Ask Claude: a different color, a louder beep, a snooze button. The preview rebuilds every time a file is saved.

    No Claude Code, or still stuck? Use the fallback

    Download alarm-clock.ipynb into your project folder, open it, pick a Python 3.10+ kernel, and run its one code cell. It writes a finished clock into apps/alarm_clock, and the preview picks it up.

    05

    The finish / 6 minutes

    Deploy from the App Builder

    Deploy sends the app to RocketRide Cloud, which builds it. Publish puts that version on your desktop.

    1. Open the Deploy tab. In the App Builder, click Deploy at the top.
    2. Click the Deploy button. Add a comment if you like, for example first clock.

      A version card appears for v1.

    3. Wait for the build. The card moves through uploaded, installing, checking and building. This takes a minute or two.

      The build finishes and the card no longer says building.

    4. Publish it. On the version card, click Publish to… and choose @me, your own desktop.
    5. Open cloud.rocketride.ai in your browser.

      Your clock is on your desktop. Open it: the second hand is moving.

    Done when

    Your clock opens on cloud.rocketride.ai and the second hand is moving.

    The build failed

    Click the failed badge on the version card to open the build log. The failure reason is at the end. Paste it into Claude and ask for a fix, check the preview, then click Deploy again.

    The Deploy tab is read-only with a namespace banner

    The app id doesn't start with your organization's developer id. The banner names the right one. The id is in three files, so ask Claude to change it, putting the banner's id in place of your_developer_id:

    prompt
    Change the developer id of apps/alarm_clock to your_developer_id in package.json, alarm_clock.rrapp and src/AppDescriptor.ts.

    Close the App Builder, open alarm_clock.rrapp again, and deploy.

    The alarm flashes but doesn't beep

    Browsers only play sound after you click on the page. Press Set alarm to turn sound on, and check the tab isn't muted.

    The clock isn't on my desktop

    The desktop picks up new apps when it refreshes. Reload cloud.rocketride.ai.

    Ship a change

    Ask Claude, check the preview, click Deploy again, and publish the new version to @me. Versions never change, so each deploy makes the next one.

    Reference

    Words you will hear

    Nothing here needs a computer science degree. Every term the steps use is in this list.

    The ideas

    AppA small web page that RocketRide shows inside its own window, with your theme and sign-in already in place.
    PipelineA chain of steps that runs in RocketRide. Data goes in one end, a result comes out the other. This project doesn't need one.
    ReactA popular library for building web pages out of components. RocketRide apps are written with it.
    BuildTurning an app's source code into the files a browser loads. RocketRide Cloud does it for you.

    The tools

    RocketRideAn open source runtime for AI pipelines and apps, with a cloud you deploy to.
    TerminalThe text window where you type commands. In your editor: Terminal, New Terminal.
    NotebookA file of cells (.ipynb) you run one at a time. Here it only holds the fallback clock.
    SDKA library that lets your code talk to a service. Here, the RocketRide Python SDK.
    rocketride commandInstalled with the SDK. init sets up a workspace, app create makes an app.
    Claude CodeA coding agent you talk to in the terminal. It reads the workspace's CLAUDE.md to learn the platform.
    API keyThe password a service gives you so your code can call it. You create one at cloud.rocketride.ai and save it in .env.
    App BuilderThe RocketRide extension's screen for an app: Design shows it live, Deploy ships it.
    PreviewThe App Builder's live view of your app. It rebuilds every time a file is saved.

    The pieces of this project

    rocketride initTurns a folder into a RocketRide project: checks the key in .env, adds the docs and CLAUDE.md.
    rocketride app createMakes a new app from RocketRide's template under apps/.
    WorkspaceYour project folder after rocketride init: your sign-in, the RocketRide docs, and the apps/ folder.
    .rrappThe file in an app folder that opens it in the App Builder.
    FallbackThe notebook's one cell. Writes a finished clock if Claude's doesn't work.
    TemplateThe starter app RocketRide creates for you, so every app has the same shape.
    Developer idYour organization's publisher name. Every app id starts with it, like acme_labs.alarm_clock.
    ManifestThe appManifest block in package.json: the app's id, name, icon and README.
    DeployUploading a new version of the app's source to RocketRide Cloud, which builds it.
    PublishChoosing who sees a version. @me is your own desktop; teams and the public store are the other choices.
    VersionOne numbered upload of the app. Versions never change, so each deploy makes the next one.
