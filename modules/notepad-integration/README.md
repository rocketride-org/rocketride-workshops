# Integrate RocketRide into an existing app

Attendees clone a small TypeScript notepad app ([`notepad-starter`](https://github.com/rocketride-org/notepad-starter)) into `./notepad-starter`, add the RocketRide TypeScript SDK, and wire one pipeline-backed feature into it. Everything runs from the notebook through `%%writefile` and shell cells, and the app runs locally at http://127.0.0.1:5173.

**Time:** 15 minutes

**Requires:** Python 3.10+ with `rocketride`, Node 20+, pnpm 10+, git, and a RocketRide Cloud account with an API key.

**Before you start:** do the at-home setup in [SETUP.md](../../SETUP.md), then open [`notepad-integration.ipynb`](notepad-integration.ipynb) in VS Code and run the Preflight cell.
