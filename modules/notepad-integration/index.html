    01

    RocketRide workshop / project 2 of 3

    Integrate RocketRide into an existing app

    Zero to Agent

    In 15 minutes you take a small TypeScript notepad that knows nothing about AI and wire a RocketRide pipeline into it. You start the project by hand in a terminal, then a notebook writes the code.

    What you are building

    notepad-starter is a tiny notepad: create, edit, delete and list notes, stored in your browser. Vite and TypeScript, no framework, small enough to read in two minutes.

    You add one feature to it: an ✨ Assist button in the editor that sends the open note to a RocketRide pipeline and shows what comes back. Most real AI work looks like this. You don't start from a blank page, you add AI to an app that already exists.

    What Assist does

    It sends the open note to a RocketRide pipeline that summarizes it in 3 to 5 bullets with Claude, and shows the bullets under the editor.

    Where RocketRide comes in

    RocketRide is an open source runtime for AI pipelines. The pipeline runs on RocketRide Cloud, and your app talks to it through the RocketRide TypeScript SDK, one client and one call.

    That means you write no model plumbing, retries or streaming code. You add the SDK, create one shared client, and call it from the button.

    03

    In the room / 4 minutes

    Start the project

    A handful of commands in a terminal: install RocketRide, sign a folder in to RocketRide Cloud, then clone the notepad and start it. You do these by hand, so you see how little it takes.

    1. Make a folder for the project, for example notepad-workshop. In your editor, open it with File, Open Folder. Then open a terminal with Terminal, New Terminal. It opens in that folder.
    2. Install the RocketRide package:
      terminal
      pip install rocketride
    3. Make the folder a RocketRide workspace. Your browser opens so you can sign in to RocketRide Cloud:
      terminal
      rocketride init --uri https://api.rocketride.ai
      It writes .env with your RocketRide address and key, plus the RocketRide docs and a CLAUDE.md for coding agents.
    4. Clone the notepad app into the folder and install it:
      terminal
      git clone https://github.com/rocketride-org/notepad-starter
cd notepad-starter
pnpm install --ignore-workspace
    5. Open a second terminal (Terminal, New Terminal), go into the app and start its dev server. Leave it running for the rest of the project:
      terminal
      cd notepad-starter
pnpm dev --host 127.0.0.1 --port 5173 --strictPort
      Open http://127.0.0.1:5173 and make a note.
    6. Save notepad-integration.ipynb into the project folder, next to notepad-starter/, and open it. Click Select Kernel in the top right, choose Python Environments, and pick the Python you ran pip with.
    Done when

    The project folder has .env, notepad-starter/ and the notebook side by side, and the notepad at 127.0.0.1:5173 keeps a note after a reload.

    Why --ignore-workspace?

    If a folder above yours has a pnpm-workspace.yaml, pnpm would use it instead of the app's own settings. The flag keeps pnpm inside notepad-starter.

    The browser sign-in doesn't open

    The command prints a sign-in link: copy it into your browser and finish there. If it still fails, check you're online and run rocketride init --uri https://api.rocketride.ai again in the project folder.

    rocketride: command not found

    pip installed it into a Scripts (Windows) or bin folder that isn't on your PATH. Run it through Python instead, which works the same: python -m rocketride.cli.main init --uri https://api.rocketride.ai (or python3, or py on Windows).

    pip can't install rocketride

    No internet, or a proxy blocking it: switch networks and run it again. If it says externally-managed-environment, your Python is a system one: make a virtual environment with python3 -m venv .venv, activate it, install there, and pick .venv in Select Kernel.

    pnpm, node or git: command not found

    Install it from the table in step 2 (npm install -g pnpm@latest for pnpm), then restart your editor: open terminals don't see a changed PATH.

    pnpm install fails or hangs

    Run it again. If it still fails, run pnpm store prune, then pnpm install --ignore-workspace again.

    Port 5173 is already in use

    Another dev server, or an earlier run, holds the port. Stop it with Ctrl+C in its terminal, or close the terminal, then run pnpm dev --host 127.0.0.1 --port 5173 --strictPort again.

    It asks me to install ipykernel

    Accept the prompt, or run python3 -m pip install ipykernel for that interpreter.

    04

    The build / 11 minutes, three stages

    Wire it in

    Connect. Then add the client. Then call your pipeline from a button.

    Run the notebook's cells top to bottom with Shift+Enter. Every cell is safe to run again. If Stage 2 or 3 doesn't work, its last cell is a skip-ahead cell that puts you exactly where the stage should have ended.

    Stage 1. Connect 1 min

    1. Run the Connect cell. It opens one RocketRide client for every later cell. The client reads the .env that rocketride init wrote, so there's no key to paste:
      notebook cell
      client = RocketRideClient()   # reads ROCKETRIDE_URI and ROCKETRIDE_APIKEY from .env in this folder
await client.connect()
    Done when

    The cell prints Found the notepad app and Connected to RocketRide.

    No .env here

    The notebook isn't in your project folder, or the folder wasn't initialized. Save the notebook next to .env and notepad-starter/, open it from there, and run the cell again.

    No module named 'rocketride'

    The notebook's kernel is a different Python from the one you ran pip install rocketride with. Pick the right one in Select Kernel, or run pip install rocketride for the kernel's Python.

    Invalid or expired access_token

    The saved key was revoked. Run rocketride init --uri https://api.rocketride.ai again in the project folder to sign in again, then restart the kernel and run the Connect cell.

    Stage 2. Add the RocketRide client 5 min

    1. In your first terminal, inside notepad-starter, add the RocketRide TypeScript SDK:
      terminal
      pnpm add --ignore-workspace rocketride@1.4.0
    2. Run the %%writefile notepad-starter/src/rocketride.ts cell. It writes one shared client that every part of the app uses:
      src/rocketride.ts
      let client: RocketRideClient | null = null;

/** One shared, connected client. Connects on first use. */
export async function getClient(): Promise<RocketRideClient> {
  if (!client) {
    client = new RocketRideClient({ uri: env.ROCKETRIDE_URI, auth: env.ROCKETRIDE_APIKEY, env });
  }
  if (!client.isConnected()) await client.connect();
  return client;
}
    3. Run the key cell. It copies your RocketRide address and key from the project's .env to notepad-starter/.env.local, where Vite reads them.
    4. Restart the dev server so Vite reads .env.local: in the terminal running it, press Ctrl+C, then start it again:
      terminal
      pnpm dev --host 127.0.0.1 --port 5173 --strictPort
    Watch for

    + rocketride 1.4.0 from pnpm, then Wrote .env.local from the notebook. The app looks the same: the client only connects when the button needs it, in Stage 3.

    Done when

    rocketride is in package.json, .env.local exists, and the app still loads in the browser after the restart.

    pnpm: ENOENT … .rocketride/client/rocketride.tgz

    pnpm picked up a pnpm-workspace.yaml from a folder above the app, which points rocketride at a local file. Run the command again with --ignore-workspace, exactly as shown.

    Stuck? Skip ahead

    Run the skip-ahead cell at the end of Stage 2. It checks out the finished client files from the app's integrated branch and writes .env.local. Then, in the notepad-starter terminal, run pnpm install --ignore-workspace and restart the dev server (Ctrl+C, then pnpm dev again).

    Stage 3. Call your pipeline from the app 5 min

    1. Run the pipeline cell. It writes the Summarize pipeline to src/assist-pipeline.json and runs it once from Python with a sample note, so you see bullets in the notebook before the app does.
    2. Run the %%writefile notepad-starter/src/assist.ts cell. It writes runAssist(), the one function the button calls:
      src/assist.ts
      export async function runAssist(note: Note): Promise<string> {
  const rr = await getClient();
  const { token } = await rr.use({ pipeline: ASSIST_PIPELINE, useExisting: true });
  const result = await rr.send(token, note.body, {}, 'text/plain');
  return String(result?.answers?.[0] ?? 'No answer came back.');
}
    3. Run the button cell. It adds the ✨ Assist button and its output panel to the editor. The app reloads by itself.
    4. Open a note, write a few sentences, and press ✨ Assist.
    Pipeline stepTakesGives
    WebhookThe note, sent as textText
    QuestionTextA question for the model
    PromptThe questionThe question plus "summarize in 3 to 5 bullets"
    Anthropic (Claude)The questionThe bullets
    ResponseThe bulletsThe answer, back to the app
    What a good answer looks like

    Three to five short lines starting with a bullet, each one a fact from your note, and nothing else. A one-line note gets one or two bullets.

    Done when

    An answer from your pipeline appears under the editor.

    The answer says LLM error, or mentions the API key

    A bad, stale or missing model key doesn't fail the run. The error comes back as the answer. The pipeline reads ROCKETRIDE_ANTHROPIC_KEY from your organization's RocketRide Variables. Ask a facilitator to check it, then try again.

    The app shows RocketRide error

    The app couldn't connect. Usually .env.local is missing, or the dev server started before it existed. Run the key cell from Stage 2 again, restart the dev server (Ctrl+C, then pnpm dev again), and reload the page.

    The app didn't change after a %%writefile cell

    The dev server isn't running, or the tab is stale. Check its terminal: if it stopped, start it again with pnpm dev --host 127.0.0.1 --port 5173 --strictPort, then reload the page.

    Stuck? Skip ahead

    Run the skip-ahead cell at the end of Stage 3. It checks out the finished feature from the integrated branch: the pipeline, runAssist() and the button.

    05

    After the build

    Clean up, then next

    Stop the pipeline and the dev server, then take the same pattern to an app you build yourself.

    Clean up

    1. Run the Clean up cell. It stops the Summarize pipeline.
    2. Stop the dev server: press Ctrl+C in the terminal running pnpm dev.
    3. Keep the project folder if you want to keep playing. It's yours.

    Take it further

    • Change what Assist does: edit the prompt's instructions in src/assist-pipeline.json, for example "Suggest a better title".
    • Add a second button that calls a different pipeline with the same client.
    • Compare your files with the app's integrated branch: git diff main integrated.
    Before you deploy an app like this

    Vite puts VITE_* variables into the browser bundle. That's fine on your laptop, but never ship a build with a real API key in it.

    Reference

    Words you will hear

    Nothing here needs a computer science degree. Every term the steps use is in this list.

    The ideas

    PipelineA chain of steps that runs in RocketRide. Data goes in one end, a result comes out the other.
    AgentAn AI that doesn't just answer. It reads a situation, makes a decision, and explains why.
    LLMLarge language model. The AI that reads and writes text.
    PromptThe written instructions you give a model or an agent.
    IntegrationAdding a new capability to an app that already exists, instead of building one from scratch.
    SDKA library that lets your code talk to a service. Here, the RocketRide TypeScript SDK.

    The tools

    RocketRideAn open source runtime for AI pipelines, with a C++ engine and a cloud you deploy to.
    NotebookA file of cells (.ipynb) you run one at a time. Text cells explain, code cells do the work.
    CellOne block in a notebook. Run it with Shift+Enter.
    KernelThe Python that runs a notebook's cells. Pick it with Select Kernel.
    %%writefileA cell that writes its contents to a file instead of running them.
    TerminalThe text window where you type commands like pnpm install.
    pnpmThe tool that installs a JavaScript project's dependencies.
    ViteThe dev server that runs the notepad and reloads it when a file changes.
    API keyThe password a service gives you so your code can call it.

    The pieces of this project

    rocketride initThe command that signs a folder in to RocketRide Cloud. It saves your address and key to .env and adds the RocketRide docs.
    WorkspaceA folder rocketride init has set up: .env, the docs, and your project's files. Here, your project folder.
    .envThe workspace's settings file. The notebook's RocketRide client reads it by itself; never commit it.
    Skip aheadThe last cell of Stages 2 and 3. Puts you where the stage should have ended.
    main and integratedThe app's two branches: the plain notepad, and the finished integration.
    Dev serverThe local server at 127.0.0.1:5173 that serves the app while you work.
    .env.localThe app's settings file. Holds your RocketRide key for local development; git ignores it.
    WebhookThe pipeline step that receives data sent to it, here the note's text.
    VariablesSettings stored in your RocketRide organization, like the model key. Pipelines read them on the server.
