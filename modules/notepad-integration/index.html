    RocketRide workshop / project 2 of 3

    Integrate RocketRide into an existing app

    Zero to Agent

    In 15 minutes you give a small notepad app an AI button. Clone the app, run three commands, paste three files.

    What you are building

    notepad-starter is a tiny notepad: create, edit and delete notes, stored in your browser. You add an ✨ Assist button that sends the open note to a RocketRide pipeline, which summarizes it in 3 to 5 bullets with Claude. The bullets appear under the editor.

    Most real AI work looks like this: not a blank page, but AI added to an app that already exists.

    Where RocketRide comes in

    A pipeline is a chain of steps that runs on RocketRide Cloud: the note goes in, Claude summarizes it, the bullets come out. The app talks to it through the RocketRide TypeScript SDK: one client, one call.

    04

    In the room / 3 minutes

    Connect RocketRide

    Save your key, then three commands.

    1. Save your key. Open notepad-starter in your editor (File, Open Folder) so you can edit its files. In the Explorer on the left, click New File and name it .env (at the top, next to package.json). Paste this, put your API key in place of both your-api-keys, and save:
      .env
      ROCKETRIDE_URI=https://api.rocketride.ai
ROCKETRIDE_APIKEY=your-api-key
VITE_ROCKETRIDE_URI=https://api.rocketride.ai
VITE_ROCKETRIDE_APIKEY=your-api-key
      The first two lines are for the rocketride command, the VITE_ lines for the app. git ignores .env, so your key never gets committed.
    2. Run these three commands in the terminal. They install RocketRide's command-line tool, make the folder a RocketRide project, and add the RocketRide SDK to the app (installing its other packages too):
      terminal
      python3 -m pip install rocketride
rocketride init
pnpm add rocketride@1.4.0
      terminal
      python -m pip install rocketride
rocketride init
pnpm add rocketride@1.4.0
      A Mac has no plain pip command, so this runs pip through Python.
    Done when

    rocketride init printed Workspace initialized against https://api.rocketride.ai and pnpm add finished without an error. A yellow Ignored build scripts: esbuild box is fine.

    Error: No authorization provided

    rocketride init didn't find your key. Check .env is next to package.json (not inside src), has your key on the ROCKETRIDE_APIKEY line, and is saved.

    UnicodeDecodeError ... byte 0xff

    .env was made in PowerShell and saved in the wrong encoding. Open it, click UTF-16 LE at the bottom right, choose Save with Encoding, then UTF-8. Always make .env with the editor's New File.

    Stored credentials ... were rejected

    The key is wrong or was revoked. Create a new one, paste it into both key lines, save, and run rocketride init again.

    rocketride or pnpm: command not found

    For rocketride, use python3 -m rocketride.cli.main init instead (Windows: python -m rocketride.cli.main init). Otherwise install the tool (Step 2), then close and reopen your terminal and cd notepad-starter again.

    1. New file: src/assist.ts

    Right-click the src folder, choose New File, name it assist.ts, and paste. This is the whole integration: it connects to RocketRide with the key from .env, describes the Summarize pipeline (webhook → question → prompt → Claude → answers), and exports runAssist(), which sends a note and returns the bullets.

    src/assist.ts
    /// <reference types="vite/client" />
import { RocketRideClient, type PipelineConfig } from 'rocketride';
import type { Note } from './notes';

// Your RocketRide address and key, from .env. Vite only passes VITE_* settings to the browser:
// fine on your laptop, but never ship a real key in a deployed app.
const env = {
  ROCKETRIDE_URI: import.meta.env.VITE_ROCKETRIDE_URI ?? 'https://api.rocketride.ai',
  ROCKETRIDE_APIKEY: import.meta.env.VITE_ROCKETRIDE_APIKEY ?? '',
};

// The Summarize pipeline: the note arrives through a webhook, becomes a question, gets the
// instructions, and goes to Claude. ${ROCKETRIDE_ANTHROPIC_KEY} is filled in on the server
// from your organization's Variables, so the model key never reaches the browser.
const PIPELINE: PipelineConfig = {
  name: 'Notepad assist',
  source: 'webhook_1',
  project_id: 'd0be2077-032f-4d96-b936-7984da5dd404',
  version: 1,
  components: [
    {
      id: 'webhook_1',
      provider: 'webhook',
      config: { hideForm: true, mode: 'Source', parameters: {}, type: 'webhook' },
    },
    {
      id: 'question_1',
      provider: 'question',
      config: {},
      input: [{ lane: 'text', from: 'webhook_1' }],
    },
    {
      id: 'prompt_1',
      provider: 'prompt',
      config: {
        instructions: ['Summarize this note in 3 to 5 short bullet points. Reply with only the bullets.'],
        parameters: {},
      },
      input: [{ lane: 'questions', from: 'question_1' }],
    },
    {
      id: 'llm_anthropic_1',
      provider: 'llm_anthropic',
      config: {
        profile: 'claude-sonnet-4-6',
        'claude-sonnet-4-6': { apikey: '${ROCKETRIDE_ANTHROPIC_KEY}' },
        parameters: {},
      },
      input: [{ lane: 'questions', from: 'prompt_1' }],
    },
    {
      id: 'response_answers_1',
      provider: 'response_answers',
      config: { laneName: 'answers' },
      input: [{ lane: 'answers', from: 'llm_anthropic_1' }],
    },
  ],
};

let client: RocketRideClient | null = null;

/** Summarizes the note with the pipeline. Returns the text to show under the editor. */
export async function runAssist(note: Note): Promise<string> {
  if (!note.body.trim()) {
    return 'Write something first.';
  }
  if (!client) {
    client = new RocketRideClient({ uri: env.ROCKETRIDE_URI, auth: env.ROCKETRIDE_APIKEY, env });
  }
  if (!client.isConnected()) {
    await client.connect();
  }
  // useExisting reuses the pipeline if it's already running.
  const { token } = await client.use({ pipeline: PIPELINE, useExisting: true });
  const result = await client.send(token, note.body, {}, 'text/plain');
  const answers = result?.answers as unknown[] | undefined;
  return String(answers?.[0] ?? 'No answer came back.');
}

    2. Replace: src/main.ts

    Open src/main.ts, select everything (Cmd+A or Ctrl+A), and paste over it. It adds the ✨ Assist button, a box for the answer, and the click that calls runAssist().

    src/main.ts
    import './style.css';
import { loadNotes, newNote, saveNotes, type Note } from './notes';
import { runAssist } from './assist';

let notes = loadNotes();
let selectedId: string | null = notes[0]?.id ?? null;

const app = document.querySelector<HTMLDivElement>('#app')!;
app.innerHTML = `
  <aside>
    <button id="new">+ New note</button>
    <ul id="list"></ul>
  </aside>
  <main id="editor"></main>
`;
const list = app.querySelector<HTMLUListElement>('#list')!;
const editor = app.querySelector<HTMLElement>('#editor')!;

function selected(): Note | undefined {
  return notes.find((n) => n.id === selectedId);
}

function update(changes: Partial<Note>): void {
  notes = notes.map((n) => (n.id === selectedId ? { ...n, ...changes, updatedAt: Date.now() } : n));
  saveNotes(notes);
  renderList();
}

function renderList(): void {
  list.replaceChildren(
    ...[...notes]
      .sort((a, b) => b.updatedAt - a.updatedAt)
      .map((n) => {
        const li = document.createElement('li');
        li.textContent = n.title || 'Untitled';
        li.className = n.id === selectedId ? 'on' : '';
        li.onclick = () => {
          selectedId = n.id;
          render();
        };
        return li;
      }),
  );
}

function renderEditor(): void {
  const note = selected();
  if (!note) {
    editor.innerHTML = '<p class="empty">No note selected. Create one to get started.</p>';
    return;
  }
  editor.innerHTML = `
    <input id="title" />
    <textarea id="body" placeholder="Write something..."></textarea>
    <div class="actions"><button id="assist">✨ Assist</button><button id="delete">Delete</button></div>
    <pre id="assist-out" hidden></pre>
  `;
  const title = editor.querySelector<HTMLInputElement>('#title')!;
  const body = editor.querySelector<HTMLTextAreaElement>('#body')!;
  title.value = note.title;
  body.value = note.body;
  title.oninput = () => update({ title: title.value });
  body.oninput = () => update({ body: body.value });
  const out = editor.querySelector<HTMLPreElement>('#assist-out')!;
  editor.querySelector<HTMLButtonElement>('#assist')!.onclick = async () => {
    out.hidden = false;
    out.textContent = 'Thinking...';
    try {
      out.textContent = await runAssist(selected()!);
    } catch (err) {
      out.textContent = `RocketRide error: ${err instanceof Error ? err.message : String(err)}`;
    }
  };
  editor.querySelector<HTMLButtonElement>('#delete')!.onclick = () => {
    notes = notes.filter((n) => n.id !== note.id);
    saveNotes(notes);
    selectedId = notes[0]?.id ?? null;
    render();
  };
}

function render(): void {
  renderList();
  renderEditor();
}

app.querySelector<HTMLButtonElement>('#new')!.onclick = () => {
  const note = newNote();
  notes = [note, ...notes];
  saveNotes(notes);
  selectedId = note.id;
  render();
};

render();

    06

    The finish / 5 minutes

    Run it

    Start the app and press the new button.

    1. Start the app:
      terminal
      pnpm dev
    2. Open http://localhost:5173, click + New note, and write or paste a paragraph.
    3. Press ✨ Assist. The box under the editor says Thinking..., then shows 3 to 5 bullets. The first press takes a few seconds while the pipeline starts.
    Done when

    Bullets summarizing your note appear under the editor.

    The box says Invalid Anthropic API key format, or the answer is empty

    ROCKETRIDE_ANTHROPIC_KEY is missing from your organization's RocketRide Variables. At a workshop, tell the facilitator. On your own, add it there with your Anthropic API key, then press Assist again.

    The box says RocketRide error: ... about anything else

    Check both VITE_ lines in .env have your key and the file is saved. Then stop the app (Ctrl+C) and run pnpm dev again: the app only reads .env when it starts.

    No Assist button, or a blank page

    A file wasn't pasted or saved. Stop the app and run pnpm build: it names the file and line with the problem. Re-copy that file's box, then pnpm dev again.

    Port 5173 is already in use

    The terminal prints the port it used instead, for example localhost:5174. Open that.

    Take it further

    • Change what Assist does: edit the instructions in src/assist.ts (for example "Suggest a better title"), save, and press Assist again.
    • Add a second button that runs a different pipeline with the same client.
    Before you deploy an app like this

    Vite puts VITE_* settings into the browser bundle. That's fine on your laptop, but never ship a build with a real API key in it.

    When you're done, press Ctrl+C in the terminal to stop the app.

    Reference

    Words you will hear

    Nothing here needs a computer science degree. Every term the steps use is in this list.

    The ideas

    PipelineA chain of steps that runs in RocketRide. Data goes in one end, a result comes out the other.
    AgentAn AI that doesn't just answer. It reads a situation, makes a decision, and explains why.
    LLMLarge language model. The AI that reads and writes text.
    PromptThe written instructions you give a model or an agent.
    IntegrationAdding a new capability to an app that already exists, instead of building one from scratch.
    SDKA library that lets your code talk to a service. Here, the RocketRide TypeScript SDK.

    The tools

    RocketRideAn open source runtime for AI pipelines, with a C++ engine and a cloud you deploy to.
    ExplorerThe file list on the left of your editor. Right-click a folder there to make a new file in it.
    TerminalThe text window where you type commands like pnpm dev.
    pnpmThe tool that installs a JavaScript project's dependencies.
    ViteThe tool that runs the notepad on your laptop and reloads it when a file changes. It reads .env when it starts.
    TypeScriptJavaScript with types. pnpm build checks it and points at mistakes.
    API keyThe password a service gives you so your code can call it.

    The pieces of this project

    rocketride initThe command that makes a folder a RocketRide project. It checks the key in .env and adds the RocketRide docs.
    .envThe project's settings file: your RocketRide address and key. git ignores it, so it never gets committed.
    VITE_The prefix Vite needs before it passes a setting from .env to the app in the browser.
    RocketRide clientThe SDK object in src/assist.ts that connects to RocketRide and runs the pipeline.
    Dev serverWhat pnpm dev starts: the app at localhost:5173 while you work.
    WebhookThe pipeline step that receives data sent to it, here the note's text.
    VariablesSettings stored in your RocketRide organization, like the model key. Pipelines read them on the server.
