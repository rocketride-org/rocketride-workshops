    01

    RocketRide workshop / project 2 of 3

    Integrate RocketRide into an existing app

    Zero to Agent

    In 15 minutes you take a small TypeScript notepad that knows nothing about AI and wire a RocketRide pipeline into it, without leaving your notebook.

    What you are building

    notepad-starter is a tiny notepad: create, edit, delete and list notes, stored in your browser. Vite and TypeScript, no framework, small enough to read in two minutes.

    You add one feature to it: an ✨ Assist button in the editor that sends the open note to a RocketRide pipeline and shows what comes back. Most real AI work looks like this. You don't start from a blank page, you add AI to an app that already exists.

    What Assist does

    It sends the open note to a RocketRide pipeline that summarizes it in 3 to 5 bullets with Claude, and shows the bullets under the editor.

    Where RocketRide comes in

    RocketRide is an open source runtime for AI pipelines. The pipeline runs on RocketRide Cloud, and your app talks to it through the RocketRide TypeScript SDK, one client and one call.

    That means you write no model plumbing, retries or streaming code. You add the SDK, create one shared client, and call it from the button.

    Before the event / 15 minutes

    Set up at home

    The project itself is 15 minutes. Done at home, setup takes another 15. On conference wifi it can take the whole session.

    What you need

    EditorVS Code, Cursor or Windsurf, with admin rights on the laptop
    Python 3.10+python3 --version. The notebook runs on it.
    Node 20+, pnpm 10+node --version, pnpm --version. The notepad app runs on them.
    gitgit --version. Stage 1 clones the app.
    Cloud accountSigned up, email confirmed, and subscribed to RocketRide Cloud
    RocketRide API keyCreated in your RocketRide Cloud account
    Model keyAn Anthropic key saved as ROCKETRIDE_ANTHROPIC_KEY in your organization's RocketRide Variables. At a workshop the facilitator sets it for everyone.

    Two shortcuts you use throughout. Command palette is Cmd+Shift+P, the search box for every command your editor knows. Extensions is Cmd+Shift+X.

    Two shortcuts you use throughout. Command palette is Ctrl+Shift+P, the search box for every command your editor knows. Extensions is Ctrl+Shift+X.

    Install the notebook extensions 3 min

    1. Open Extensions and search Python. Install the one from Microsoft (ms-python.python).
    2. Search Jupyter and install it too (ms-toolsai.jupyter).
    3. Reload the window if it asks.
    Done when

    Both extensions show as installed, and a new .ipynb file opens as a notebook with cells.

    Using Cursor or Windsurf?

    They install from Open VSX rather than the VS Code marketplace. Python and Jupyter are published there, so the same searches work.

    Install Python 3 min

    1. Check your version. If it's older than 3.10, install a current one from python.org.
    2. That's all. The notebook's Preflight cell installs the RocketRide SDK into that Python for you.
    On Windows

    Use python --version instead of python3 --version, or the launcher: py --version.

    Install Node, pnpm and git 3 min

    ToolCheckInstall
    Node 20+node --versionnodejs.org
    pnpm 10+pnpm --versionnpm install -g pnpm@latest
    gitgit --versiongit-scm.com
    Why pnpm and not npm?

    The notepad app pins pnpm in its package.json, and RocketRide's own apps use it. After installing any of these, restart your editor so the notebook sees the new PATH.

    Save your API key 3 min

    Do this now. A missing key is the most common thing that stops people in the room.

    1. Sign in to RocketRide Cloud, start a subscription, and create an API key.
    2. Make a folder for the workshop. In it, create a file called .env:
      .env
      ROCKETRIDE_APIKEY=your-api-key
ROCKETRIDE_URI=https://api.rocketride.ai
    Keep it out of the notebook

    Never paste your key into a cell, and never commit a .env file. If there is no .env, the notebook's Config cell asks for the key and keeps it only for the session.

    Get the notebook 3 min

    Download notepad-integration.ipynb View on GitHub
    1. Save the notebook into the folder with your .env, and open the folder with File, Open Folder.
    2. Open the notebook. Click Select Kernel in the top right, choose Python Environments, and pick Python 3.10 or newer.
    3. Run the Preflight cell with Shift+Enter.
    Done when

    Preflight prints a green ✅ ready.

    It says Couldn't install the RocketRide SDK

    The cell prints pip's error. Usually it's no internet, or a VPN or proxy blocking it. Switch networks, then run Preflight again.

    It asks me to install ipykernel

    Accept the prompt, or run python3 -m pip install ipykernel for that interpreter.

    Node, pnpm or git is missing or too old

    Preflight names the fix for each one. Install or upgrade, then restart your editor: a running kernel doesn't see a changed PATH.

    Stuck on any of this?

    Come 10 minutes early. A facilitator runs a help desk before the start, and that is the only setup help there is time for. Before then, the RocketRide Discord is the fastest route, and the docs are at docs.rocketride.org.

    Done when

    All three cells ran without a red error and the last one says Connected.

    The Config cell keeps asking for my key

    There is no ROCKETRIDE_APIKEY in your environment or in a .env next to the notebook. Paste the key when asked: it's kept for the session. To skip the prompt next time, create the .env from Step 2.

    Connect fails with Invalid or expired access_token

    The key is wrong or was revoked. Create a new one in RocketRide Cloud, update your .env, restart the kernel and run the three cells again.

    04

    The build / 13 minutes, three stages

    Wire it in

    Get the app running. Then add the client. Then call your pipeline from a button.

    Each stage ends with something you can see in the browser. If a stage doesn't work, the last cell of that stage is a skip-ahead cell that puts you exactly where the stage should have ended.

    Stage 1. Get the notepad running 3 min

    1. Run the clone cell. It clones the app into ./notepad-starter, or skips if it's already there.
      notebook cell
      # Clone the notepad app into ./notepad-starter (skips if it's already there)
if (NOTEPAD / ".git").exists():
    print("Already cloned:", NOTEPAD.resolve())
else:
    sh("git", "clone", NOTEPAD_REPO, str(NOTEPAD))
    2. Run the install cell: pnpm install, about a minute on slow wifi.
    3. Run the start cell. It starts the dev server in the background and prints the address.
    4. Open http://127.0.0.1:5173 and make a note.
    Done when

    The notepad is open in your browser and keeps a note after a reload.

    Port 5173 is in use, or it says did not start

    Another dev server, or an earlier run, holds port 5173. Run the Clean up cell at the bottom, or stop whatever owns the port, then run the start cell again.

    pnpm install fails or hangs

    Run the cell again. If it still fails, run pnpm store prune in a terminal, then run it again.

    Stuck? Skip ahead

    Run the cell headed # Skip ahead: run this only if the stage above didn't work at the end of Stage 1. It resets the app to the plain starter and reinstalls. Then run the start cell again.

    Stage 2. Add the RocketRide client 5 min

    1. Run the cell that adds the SDK: pnpm add rocketride@1.4.0.
    2. Run the %%writefile notepad-starter/src/rocketride.ts cell. It writes one shared client that every part of the app uses:
      src/rocketride.ts
      let client: RocketRideClient | null = null;

/** One shared, connected client. Connects on first use. */
export async function getClient(): Promise<RocketRideClient> {
  if (!client) {
    client = new RocketRideClient({ uri: env.ROCKETRIDE_URI, auth: env.ROCKETRIDE_APIKEY, env });
  }
  if (!client.isConnected()) await client.connect();
  return client;
}
    3. Run the key cell. It writes your RocketRide key to notepad-starter/.env.local, where Vite reads it, and restarts the dev server so it picks the key up.
    Watch for

    + rocketride 1.4.0 from pnpm, then Wrote .env.local and the notepad address again. The app looks the same: the client only connects when the button needs it, in Stage 3.

    Done when

    rocketride is in package.json, .env.local exists, and the app still loads in the browser.

    Stuck? Skip ahead

    Run the skip-ahead cell at the end of Stage 2. It checks out the finished client files from the app's integrated branch, reinstalls, and writes .env.local.

    Stage 3. Call your pipeline from the app 5 min

    1. Run the pipeline cell. It writes the Summarize pipeline to src/assist-pipeline.json and runs it once from Python with a sample note, so you see bullets in the notebook before the app does.
    2. Run the %%writefile notepad-starter/src/assist.ts cell. It writes runAssist(), the one function the button calls:
      src/assist.ts
      export async function runAssist(note: Note): Promise<string> {
  const rr = await getClient();
  const { token } = await rr.use({ pipeline: ASSIST_PIPELINE, useExisting: true });
  const result = await rr.send(token, note.body, {}, 'text/plain');
  return String(result?.answers?.[0] ?? 'No answer came back.');
}
    3. Run the button cell. It adds the ✨ Assist button and its output panel to the editor. The app reloads by itself.
    4. Open a note, write a few sentences, and press ✨ Assist.
    Pipeline stepTakesGives
    WebhookThe note, sent as textText
    QuestionTextA question for the model
    PromptThe questionThe question plus "summarize in 3 to 5 bullets"
    Anthropic (Claude)The questionThe bullets
    ResponseThe bulletsThe answer, back to the app
    What a good answer looks like

    Three to five short lines starting with a bullet, each one a fact from your note, and nothing else. A one-line note gets one or two bullets.

    Done when

    An answer from your pipeline appears under the editor.

    The answer says LLM error, or mentions the API key

    A bad, stale or missing model key doesn't fail the run. The error comes back as the answer. The pipeline reads ROCKETRIDE_ANTHROPIC_KEY from your organization's RocketRide Variables. Ask a facilitator to check it, then try again.

    The app shows RocketRide error

    The app couldn't connect. Usually .env.local is missing, or the dev server started before it existed. Run the key cell from Stage 2 again: it rewrites the file and restarts the dev server. Then reload the page.

    The app didn't change after a %%writefile cell

    The dev server isn't running, or the tab is stale. Run the start cell from Stage 1 again and reload the page.

    Stuck? Skip ahead

    Run the skip-ahead cell at the end of Stage 3. It checks out the finished feature from the integrated branch: the pipeline, runAssist() and the button.

    05

    After the build

    Clean up, then next

    Stop what the notebook started, then take the same pattern to an app you build yourself.

    Clean up

    1. Run the Clean up cell. It stops the dev server this notebook started, and the Summarize pipeline.
    2. Keep ./notepad-starter if you want to keep playing. It's yours.

    Take it further

    • Change what Assist does: edit the prompt's instructions in src/assist-pipeline.json, for example "Suggest a better title".
    • Add a second button that calls a different pipeline with the same client.
    • Compare your files with the app's integrated branch: git diff main integrated.
    Before you deploy an app like this

    Vite puts VITE_* variables into the browser bundle. That's fine on your laptop, but never ship a build with a real API key in it.

    Reference

    Words you will hear

    Nothing here needs a computer science degree. Every term the steps use is in this list.

    The ideas

    PipelineA chain of steps that runs in RocketRide. Data goes in one end, a result comes out the other.
    AgentAn AI that doesn't just answer. It reads a situation, makes a decision, and explains why.
    LLMLarge language model. The AI that reads and writes text.
    PromptThe written instructions you give a model or an agent.
    IntegrationAdding a new capability to an app that already exists, instead of building one from scratch.
    SDKA library that lets your code talk to a service. Here, the RocketRide TypeScript SDK.

    The tools

    RocketRideAn open source runtime for AI pipelines, with a C++ engine and a cloud you deploy to.
    NotebookA file of cells (.ipynb) you run one at a time. Text cells explain, code cells do the work.
    CellOne block in a notebook. Run it with Shift+Enter.
    KernelThe Python that runs a notebook's cells. Pick it with Select Kernel.
    %%writefileA cell that writes its contents to a file instead of running them.
    TerminalThe text window where you type commands like pnpm install.
    pnpmThe tool that installs a JavaScript project's dependencies.
    ViteThe dev server that runs the notepad and reloads it when a file changes.
    API keyThe password a service gives you so your code can call it.

    The pieces of this project

    PreflightThe first code cell. Installs the SDK, checks your machine and prints ready.
    ConfigThe only cell that reads your environment. Every later cell uses its CONFIG.
    ConnectOpens the shared RocketRide client.
    Skip aheadThe last cell of each stage. Puts you where the stage should have ended.
    main and integratedThe app's two branches: the plain notepad, and the finished integration.
    Dev serverThe local server at 127.0.0.1:5173 that serves the app while you work.
    .env.localThe app's settings file. Holds your RocketRide key for local development; git ignores it.
    WebhookThe pipeline step that receives data sent to it, here the note's text.
    VariablesSettings stored in your RocketRide organization, like the model key. Pipelines read them on the server.
